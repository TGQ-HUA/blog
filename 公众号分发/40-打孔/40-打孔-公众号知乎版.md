# 共板法兰打孔，旧规则和新规则差在哪——一个孔距算错，整排法兰全废

> 车间老张拿了块法兰料来找我："唐哥，你看这个孔——边距75mm，到中间变成130多，两头稀中间密。"甲方拍了照，问这风管质量能好？我无言以对。

---

## 一、一个投诉

上个月车间老张拿了块法兰料来找我。

"唐哥，你看看这个孔——边距75mm，到中间变成130多，两头稀中间密，装上去看着就不对劲。"

这是旧规则"固定首孔"打出来的——首孔固定110mm边距，中间再均分剩下的。边长800mm还行，碰到650mm、950mm这种不上不下的尺寸，孔距特别难看。

甲方拍了照，说"法兰孔距都不均匀，这风管质量能好？"

## 二、旧规则：固定首孔

核心：两端首孔固定边距110mm，中间再均分。

800mm边长，要求孔距≤140mm：
```
中间区域 = 800 - 220 = 580mm
段数 = Ceil(580/140) = 5段 → 6个孔
实际中间孔距 = 580/5 = 116mm
```

两端110mm，中间116mm，还行。换650mm试试：
```
中间区域 = 650 - 220 = 430mm
段数 = Ceil(430/140) = 4段 → 5个孔
实际中间孔距 = 430/4 = 107.5mm
```

两端110mm，中间107.5mm，差2.5mm。孔一多就是"两边松中间紧"。

## 三、新规则：整边均分

核心：整条边等分，孔距均匀。

800mm，要求≤140mm：
```
段数 = Ceil(800/140) = 6段 → 5个孔
实际孔距 = 800/6 = 133.33mm ✓
```

650mm：
```
段数 = Ceil(650/140) = 5段 → 4个孔
实际孔距 = 650/5 = 130mm ✓
```

每个孔距一模一样，甲方拿尺子量任何一个都一样。

## 四、对比

| 对比项 | 固定首孔（旧） | 整边均分（新） |
|--------|:-----------:|:-----------:|
| 首孔边距 | 固定110mm | 自适应 |
| 孔数算法 | 中间区域均分 | 整边均分 |
| 小边不打 | < 220mm | < 150mm |
| 孔距均匀性 | 两端和中间不一样 | 全部均匀 ✅ |
| 计算复杂度 | 两步计算 | 一步到位 |

## 五、一个例外

孔距<100mm时，还是用固定首孔规则。因为边长太短，整边均分算出来的孔距可能比要求的还大。

## 六、这个事说明什么

**越小的环节，越能看出一个厂的底子。** 打孔规则十年没变过的厂不在少数。不是不能改，是没人想过要改——"以前就是这么干的"。

改一个孔距算法，成本为零。改完之后车间顺眼了、甲方没话说了、返工少了。这种改动不做，不是技术问题，是意识问题。
