## 一、一个真事

上个月工地上的事：安装队进场三天，被监理叫停。二层风管支架间距普遍超标，最长一段，两根支架隔了5米多。

安装队长的解释很直接："图纸上没标支架位置，我们按经验装的。"

这批风管长边1250mm。按GB50243-2016第6.1.1条，金属水平风管长边大于400mm，支吊架间距不得超过3米。他们装了4米多，自己还觉得挺密。

车间觉得够密了，规范说不够。中间差多少，拿尺子量了才知道。

## 二、规范怎么规定的

GB50243-2016第6.1.1条，支吊架最大间距：

| 风管类型 | 长边 ≤ 400mm | 长边 > 400mm |
|----------|-------------|-------------|
| 水平金属风管 | ≤ 4.0m | ≤ 3.0m |
| 水平非金属风管 | ≤ 3.0m | ≤ 2.5m |
| 垂直金属风管 | ≤ 4.0m（单根不少于2个固定点） | |
| 垂直非金属风管 | ≤ 3.0m（单根不少于2个固定点） | |

两个点最容易记混：

**第一，4米只属于小风管。** 长边一过400mm，立马降到3米。市面上大部分空调风管长边都在400以上，实际执行标准就是3米。安装队常记成"4米差不多"，是把小风管的数记到大风管头上了。

**第二，非金属风管更严。** 防火板、玻纤复合风管刚度不如铁皮，间距必须更密。现场常见非金属风管按金属标准装，监理较真，就是不合格项。

## 三、除了间距，还有三个参数容易漏

**吊杆直径**：风管长边大于1250mm时，吊杆直径不得小于10mm。8mm吊杆装大尺寸风管，那不是省料，是拿安全赌。

**横担规格**：长边≤630mm用角钢L25×3；超过2000mm必须上槽钢。中间尺寸L30×4、L40×4逐级加码，是厂里多年干出来的惯例。

**防晃支架**：风管末端、转弯处、分支处，以及垂直风管每隔两层，须设防晃支架。最容易被省掉的一项——只装承重不装防晃，风机一启动，管子晃给你看。

**别忘了排烟管**：GB51251-2017第7章规定，排烟风管支吊架间距不大于空调风管间距的0.8倍。空调金属管3米，排烟管最多2.4米。

## 四、用工具把规范翻译成结果

一个项目几百段风管，逐段手算不现实。我们做了个WPS表格模板：

- 输入风管长边 → IF函数自动匹配间距（400mm是分界线）
- 输入直管长度 → 自动算支架个数（长度÷间距−1，向上取整）
- 标注管段位置 → 自动判断要不要防晃支架
- 汇总 → 直接出采购清单（吊杆长度×数量、横担规格×数量）

核心逻辑就三层判断：长边≤400取4米，>400取3米，非金属再减0.5米，一层IF嵌套搞定。

以前靠师傅记忆，容易记混。现在表格一拉，该3米就3米，该2.5米就2.5米，没有"我觉得差不多"的空间。

## 五、支架问题的行业根源

支架是"看不见的成本"。业主盯漏风量、盯法兰平整度，支架埋在吊顶里，验收时很少有人专门去量。有些安装队就在这上面省——一个项目省几十根吊杆，看着不多，出了事就是大事。

我们早年也吃过亏。商场空调开机调试，一段8米风管没装防晃支架，风机一启动，整段管子抖得像筛糠。全部返工，人工材料比一开始做足还贵。此后技术部定了硬规矩：支架间距按规范上限执行，一毫米都不商量。WPS模板也是由此而来——把判断交给表格，别交给个人感觉。

图纸不画支架这个现状，短期改不了。那就把该记的写进表里，谁来了都能照着干。
