# 风管清量，图纸差一个数、车间白干一截——跟单部和技术部的对接，我们厂定了规矩

上周三，跟单部小周在群里甩了套图，就一句话："急单，今天要清量。"

我打开图一看，头就大了。系统范围没写——是防排烟还是通风空调？接口没写——共板还是角铁？料厚没写——客户自订还是按国标？三无图纸。清量这活，图纸上差一个数，车间就白干一截。

## 一、先分清两个活：清量和分节

很多厂把这两个词混着用，其实不是一回事。

**清量**，是按客户要求提取风管量（净面积），顺带统计设备数量，有接口的话还能给出大概的材料面积。说白了就是算账，把图上画的管子变成数字。

**分节**，是按客户要求把风管系统切成一段一段。这活要建模、要标注系统号，优化的时候还得避开风口分节，耗时长，是清量里最磨人的部分。

接单之前先问清楚：要清量，还是要分节，还是两个都要。

## 二、清量前必须问清的几件事

跟单部发图过来，图纸可以急，信息不能省。我们厂现在要求，发清量单必须带齐这几样：

- **客户需求**：风管清量、设备清量，还是系统分节
- **系统范围**：防排烟系统 / 通风空调系统 / 卫生间系统 / 厨房排油烟系统
- **风管接口**：共板、角铁、直边、翻边、插条边，五种接口，料不一样，价不一样
- **料厚要求**：客户自订、图纸说明，还是按国标
- **时限要求**：什么时候要

这五样没齐，技术部有权先不接单，回群里问清楚再说。白纸黑字写下来，两边都省事。

## 三、对接流程怎么定的

1. 跟单部通过清量分节群发图纸和要求
2. 技术部按工作安排给出清单，排不过来在群里说明原因和时间
3. 分节问题比较多，技术部在群里提出，由跟单部跟客户反馈
4. 分节项目交付时附带三样东西：异形件大样图、材料清单、分节图纸
5. **下单图纸必须客户确认 + 技术部内部二次审核，缺一不可**

第 5 条是拿教训换来的。以前有过一次，分节图没发客户确认就下了单，客户要的风口位置和图上对不上，货都排进生产线了才喊停。从那以后，这条写进了指导书，还加了句免责声明：图纸错漏或未确认直接下单导致的出错，技术部不担责。话是硬了点，但管用。

## 四、特殊要求必须书面

管件出图还有个规矩：所有特殊要求——工艺、尺寸公差、材质、表面处理、验收标准——必须书面形式明确，不得仅口头沟通。出货判定质量，以订单书面备注加技术图纸标注为唯一依据。口头交代的工艺要求，出货后扯起皮来没有凭据，这坑我们踩过。

## 五、清量前核对清单

| 核对项 | 要问清楚的内容 | 缺了会怎样 |
|--------|---------------|-----------|
| 客户需求 | 清量 / 设备清量 / 系统分节 | 方向搞错，白算一遍 |
| 系统范围 | 防排烟、通风空调、卫生间、厨房排油烟 | 漏算一个系统，量对不上 |
| 风管接口 | 共板 / 角铁 / 直边 / 翻边 / 插条边 | 接口算错，料差一截 |
| 料厚要求 | 客户自订 / 图纸说明 / 国标 | 厚度错，强度不达标 |
| 时限要求 | 什么时候要 | 排不过来，耽误下单 |
| 图纸确认 | 客户确认 + 内部二次审核 | 出错没人认账 |

这张表贴在清量分节群里，谁发单谁先自查。缺项的，退回问齐了再接。

现在小周发图过来，第一句就带齐了："防排烟系统，共板，0.75，三天内要。"群里连多余的话都不用问。老李在车间听说这事，乐了："跟单部现在比你们技术部还专业。"

规矩这东西，立的时候麻烦，立完了省心。
