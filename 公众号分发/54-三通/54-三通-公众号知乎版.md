# 三通不是三根管拼一起——风管三通的规矩，图纸越含糊越容易错

上周车间老赵拿着一张三通的图来找我，说排版的人把支口位置画偏了，支管接上去歪着一截，现场焊工骂骂咧咧返工。我一看图，问题不在排版，在做单——单子上压根没写支口怎么对，排版师傅按自己的习惯填了个位置，跟现场实际走向对不上。

客户单子上就一句"侧三通：500×200-250×200-320×200—长720—R200—2节"。支口对中还是偏边？图纸上没画，电话里没说，排版师傅自由发挥，一发挥就出错。

## 一、三通不是三根管拼一起，是三个口的位置规矩

先分清三通有几种。按我们厂《管件排版规范手册》B.05 的分类，矩形三通就三类：

| 类型 | 别称 | 长什么样 |
|------|------|---------|
| 正三通 | 蝴蝶 | 两侧对称分支，像个蝴蝶 |
| 正三通 | T 型 | 单侧直分支，像个 T |
| 侧三通 | — | 侧面斜分支，支管斜着出去 |

客户说"三通"，多数人脑子里是 T 型，但现场最常见的其实是侧三通和蝴蝶型。做单第一件事就是分清楚：客户说的"三通"到底是哪个，三个口的尺寸各是多少。这个不问清，后面全错。

## 二、第一条规矩：支口默认对中，没写清就问

三通最要命的是支口位置。手册 B.05.01.2 写得明白：**对口默认对中**（具体参见图纸）。三个口的中心线对齐，这是默认值，但"默认"两个字最坑人——因为不是每个客户都懂"对中"是什么意思，图纸上不画，做单的不问，排版师傅一猜就歪。

我们厂的规矩：做单时支口位置必须显式写出来，写"对中"两个字。图纸上有明确标注的按图纸，没有的默认对中，但贴梁贴墙、走管避让的活，先打电话问一句。多问一句话，省车间半天返工。

## 三、第二条规矩：支口不等高，先加大小头改成等高

三通三个口高度不一样，是第二个高频坑。比如底口 500×200，侧口 320×150，高度差 50。硬做？不行。手册 B.05.01.2 的规定：**支口不等高 → 商榷加大小头，先改成等高**。

意思是，不等高的支口，别硬拼，先跟客户商量加一节变径（大小头），把支口高度拉平了再做三通。我们以前图省事，不等高硬做，做出来支管接口处扭曲，法兰对不上，漏风返工，算下来比加个大小头贵多了。

## 四、第三条规矩：变径时默认底平，偏差决定用内弧还是内菱角

三通带变径（三个口尺寸不一样）是常态。变径时的对齐方式，手册 B.05.02.1.2 给了明确的决策：

```
变径时默认底平：
  偏差 ≤ 100 → 内弧
  偏差 > 100 → 内菱角
```

"底平"就是底面齐平。偏差小（≤100mm）用内弧过渡，圆滑好看；偏差大（>100mm）用内菱角，直线过渡省料好做。这个决策做单界面里是自动的，但排版的人得看懂为什么——内弧费料，内菱角省料，偏差大了还硬做内弧，弧度太陡，咬口都咬不住。

## 五、做单和算量：一张单子写清楚，别让师傅猜

手册 B.05.02 里三通有标准做单格式，照抄就行：

```
侧三通：
底宽——500  底高——200  顶宽——250  顶高——200
侧宽——320  侧高——200  长——720  嵌入量-125
顶偏移-对中  侧偏移-对中  侧半径-R200
编号：Z5-1  成型方式：5片式  数量：2
接口：共板  材质/料厚：镀锌/0.75  接缝：大小边
```

注意两个细节：**偏移必须写"对中"**（不能空着），**成型方式写 5 片式**——三通是异形件，5 片式是标准做法，别让师傅自己琢磨怎么下料。面积公式（B.05.02.1.4）：

```
侧三通：(底宽+底高+大小边×2)×2×(中心线A+接口×2)
        + (侧宽+侧高+大小边×2)×2×(中心线B+接口)
```

这个公式是跟车间对账用的，报价、算料都靠它，别自己发明，不然算出来的面积跟车间实际下料对不上，账就乱了。

补充一条：三通支口宽（平面边长）≥500mm 的时候，内弧半径和端口边长的比值又够小（≤0.25），按 B.07.01 导流片规则，就得考虑加导流片了——两条件同时满足才加，缺一条不用。导流片数量 = 平面边长 ÷ 500，最多 4 片，间距不小于 200mm。这条是跟三通配套的，做单的时候顺带查一眼，别等装完了风量不够再补。

## 六、图纸越含糊的件，越考验做单的人

三通在图纸上就一个符号，支口位置、偏法、变径方式，设计院基本不画全，全压在排版和做单的人身上。老师傅看一眼现场就知道支口该往哪偏，新人照着单子填，填完就下料，错了才知道问。

这不是谁笨，是没地方查。GB50243-2016《通风与空调工程施工质量验收规范》第 4.2.2 条是强制性条文，材料品种规格必须符合设计要求；第 4.3 条又对风管制作偏差卡得死（对角线之差超 3mm 就超标）——材料、精度都有国标兜底，唯独"支口往哪偏"这种活儿，国标管不着，全靠厂里自己的规矩。我们把这些写进手册贴在工位上，谁来了都能翻，不用等师傅带三年才摸到门道。

## 实操：有同行问三通怎么做单不踩坑

就按这张表来，打印出来贴工位上：

| 项目 | 规矩 | 依据 |
|------|------|------|
| 类型 | 先分清正三通（蝴蝶/T型）还是侧三通，三个口尺寸写全 | B.05.01.1 |
| 支口位置 | 默认对中，必须显式写"对中"，贴梁贴墙先问一句 | B.05.01.2 |
| 支口不等高 | 不硬做，加大小头改成等高 | B.05.01.2 |
| 变径对齐 | 默认底平；偏差≤100 内弧，>100 内菱角 | B.05.02.1.2 |
| 成型方式 | 5 片式，别让师傅自己琢磨 | B.05.02.1.3 |
| 导流片 | 支口≥500 且内弧半径/边长≤0.25 才加，最多 4 片 | B.07.01 |
| 面积公式 | (底宽+底高+大小边×2)×2×(中心线+接口×2)…，跟车间对账用 | B.05.02.1.4 |

## 结尾

老赵那张三通后来重做了，单子上补了"顶偏移-对中、侧偏移-对中"一行字，车间半小时出活，现场一次装上。做单的小刘现在接三通的活，第一句先问客户："三个口尺寸多少？支口对中还是偏边？"客户说以前没人问这么细。挺好，问细了，车间才不用返工。
