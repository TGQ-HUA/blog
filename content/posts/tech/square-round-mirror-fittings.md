有同行发来一张图，图上就一行字：主方圆侧 (600×500)×Φ400 — 长700 — 1节。他问我，这算方管还是算圆管，料按哪一套下。

他卡住的地方我懂。这件在我们这儿的名字叫主方侧圆，一件管子上，方的是主管，圆的是侧边接出去的支咀，两种形状拼在同一个件上。名字里两个形状各占一半，接缝和算量的规矩也就各走各的。

## 四个字，前两个字说主管

主方侧圆拆开念：主方是主管，方管；侧圆是侧边接出去的支咀，圆管。客户口头上常写成“主方圆侧”，说的是同一件东西。

调个头就是另一件：主圆侧方。主管是圆管，侧边接出来的是方支咀。

这两件在我们排版规范里是分开编号的，前一节是主方侧圆，后一节是主圆侧方，类型、接缝设定、算量公式各有一份。它们长得像一对镜子，抄是抄不得的。

类型上也有差别。主方侧圆有三种：T 型直角、45°、45°+45°；主圆侧方只有两种：T 型直角、45°。

## 接缝：圆的那截归圆管，方的那截归方管

一件管子上同时有方和圆，最容易翻车的就是接缝。有人图省事，整件按方管的规矩配一遍，圆支咀那截的余量就配错了。

圆管有圆管的一套，看料厚：料厚到 0.7 毫米及以上，走直焊边，排版不加缝；不到 0.7 毫米，走缝焊 5，也就是常说的碰焊 5，单边叠 5 毫米。

方管那套看的是接口形式和咬口余量，方接口走共板，接缝按咬口类的余量配。

分到这两件上：

- 主方侧圆：方接口走共板，主管接缝是大小边，侧圆支咀按圆管那一套来接，做单示例里填的是碰焊 5。
- 主圆侧方：方接口还是共板，主圆管的接缝设定跟着圆直管那一套走，方支咀的接缝是大小边。

规律就一句：哪一截是圆的，按圆管配；哪一截是方的，按方管配。整件按一套配，总有一截要配歪。

## 算量：主管一段，支咀一段

面积算式两条，骨架是一样的，都是主管展开加支咀展开：

主方侧圆：(宽+高+大小边)×2×(主管长+接口×2) + 3.14×支直径×支咀长

主圆侧方：3.14×主管径×中心线A + (宽+高+大小边)×2×(支长+接口×2)

两个式子摆一起看就清楚了：方的那截用 (宽+高+大小边)×2，带着大小边这一项；圆的那截用 3.14 乘直径。哪一截归哪一截，看主管是谁。

有个细节容易漏：大小边是咬口的余量，只在方的那一截有，圆支咀那边不加。

## 录单的时候，规格分两栏填

有同行问过我们这两件的单子怎么录，我把两件并排放一张表，对着填就行：

| | 主方侧圆 | 主圆侧方 |
|------|---------|---------|
| 主管 | 方管 600×500 | 圆管 Φ600 |
| 支咀 | 圆 Φ400 | 方 500×400 |
| 类型 | T 型直角 / 45° / 45°+45° | T 型直角 / 45° |
| 主管接缝 | 大小边 | 同圆直管设定 |
| 支咀接缝 | 同圆弯头设定（碰焊 5） | 大小边 |
| 规格（1） | 600　500 | Φ600 |
| 规格（2） | Φ400【*2】 | 500　400 |
| 长度栏 | 主管长 700 | 主管长 700 |
| 面积 | (宽+高+大小边)×2×(主管长+接口×2) + 3.14×支直径×支咀长 | 3.14×主管径×中心线A + (宽+高+大小边)×2×(支长+接口×2) |
| 名称写法 | 【主方圆侧】T 型直角 | 【主圆侧方】T 型直角 |

规格（1）那栏放主管，规格（2）那栏放支咀，两件的顺序正好换过来。客户只丢一句“主方圆侧 (600×500)×Φ400”，我们还得把类型、支咀长、接口、料厚补齐，这张单才排得出来。

## 一件管子上两种工艺，出错的多在这儿

JGJ141-2017 第 6 章讲风管配件，光三通就分了插接三通、T 型三通、Y 型三通、裤裆三通四种，Y 型的夹角在送排风系统里取 30° 到 45°，除尘系统收在 30° 以内。

分类分得这么细，往下传，传到车间那一头，常常就剩名称后面几个字。名称写全了，做的人才知道按哪一套配；名称含糊，做的人只能凭经验猜，猜错的账落在车间。

风管厂里“一件上两种工艺”的活不止这两件。这类活做得少，手里没手感，所以每次都得回头翻一遍规范，翻两分钟，比切错一块板划算。

## 实操上注意这几条

接到这类件，先把三句话问完：

| 先问 | 为什么 |
|------|--------|
| 主管是方还是圆 | 决定这件是主方侧圆还是主圆侧方，接缝跟算量都跟着换 |
| 支咀什么形状、多大 | 决定规格（2）填 Φ400【*2】 还是 500　400 |
| 是 T 型直角还是 45°，主管多长 | 决定排版方式和长度栏 |

三句话问完，客户那句“主方圆侧”里缺的东西基本就补齐了。剩下的是排版的事，那一步反倒简单。

技术部新来的录单员头一回碰这类件，问的也是这三个问题。她把图发给我看的时候，我让她先别急着填单——名字里前两个字是主管，这句话记住了，接缝和算量就不会配反。
