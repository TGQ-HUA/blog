## 引子：一个三通，车间装不上

上个月车间老周拿着一张单子来找我，说"这活干不了"。

我一看，单子上写着"正三通：600/400/400"。我问怎么了，他说：三个口子，哪个是主口？哪个朝上？哪个是支咀？单子上一个字没写，师傅只能猜。猜对了算运气，猜错了整节报废。

我们跟甲方对过，甲方说是设计院图纸就这么标的，他们照抄。我又翻出以前几家厂的下单记录——同一个蝴蝶三通，五家厂五种写法：

- "600变两个400"
- "600×300三通"
- "正三通 600/400/400"
- "三通 600，支400×2"
- "600三通带两咀"

车间师傅说，光看这些单子，他能做出五种不一样的东西来。

## 正文：三通四通录单，到底该怎么写

这事的根子在于：**三通不是三根管拼一起**（这个我们写过），它有三个甚至四个口，每个口的规格、朝向、大小都不一样。录单的人不把话说全，就是把判断责任甩给车间师傅。

### 一、先把"口"的名字定死

我们厂定的规矩，每个口都有固定叫法（见管件排版规范手册 N.06）：

| 管件 | 规格(1) | 规格(2) | 规格(3) | 规格(4) | 长度 / R |
|------|---------|---------|---------|---------|----------|
| 正三通_蝴蝶（方） | 上口 | 支咀1(大) | 支咀2 | — | R 角 |
| 正三通_T型（方） | 主口 | 支咀1(大) | 支咀2 | — | R 角 |
| 侧三通_参照（方） | 主口 | 顶口 | 支咀2 | — | 支咀1 + 600 |
| 四通_参照（方） | 主口 | 顶口 | 支咀1(大) | 支咀2 | 支咀1(大) + 600 |
| 侧三通_45°（圆） | 上口 | 顶口 | 支咀1 | [ +2 ] | 根据支咀1定 |
| Y形三通（圆） | 主口 | 支咀1(大) | 支咀2 | [ +2 ] | 无 |
| Y形三通_裤型（圆） | 主口 | 支咀1(大) | 支咀2 | [ +2 ] | 无 |
| 正三通_背部人形（圆） | 主口 | 支咀1(大) | 支咀2 | [ +2 ] | R 角 |
| 四通_十字直角（圆） | 主口 | 顶口 | 支咀1(大) | 支咀2[ +2 ] | 支咀1(大) + 1200 |

几个容易踩的坑：

**第一，主口和支咀必须分清。** 侧三通和正三通不一样，侧三通有个"顶口"，规格(1)(2)(3)(4)的顺序是固定的。写"600/400/400"这种，谁也不知道哪个是哪个。我们的规矩是：规格按表里的顺序写，第一位永远是主口或上口，后面才是支咀，支咀大的写前面。

**第二，圆管件规格里标的 [ +2 ]，是口径调整量。** 侧三通 45° 和 Y 形三通，支咀2 那里标 [ +2 ]，指的是圆管口径要跟着法兰口调整——圆法兰的内尺会吃掉 4 毫米，管口不调整就套不进去或者松垮。规矩是：直口（无法兰）正尺寸不调整，活法兰或点焊法兰 +2，满焊法兰 +4。所以 [ +2 ] 是默认最常见的写法。这个标记丢了，法兰套不进去，现场拿锤子敲，敲完不是裂就是漏风。

**第三，长度不是随便给的。** 方四通的长度 = 支咀1(大) + 600，圆四通十字直角的长度 = 支咀1(大) + 1200。这是排版出来的经验值——管子总长要够安装，短了现场接不上。录单的人按这个公式算，不用每次去问师傅。

### 二、书写格式：一段话把管子说全

光有口名还不够，书写格式也得统一。我们厂的通用写法：

| 管件 | 通用格式 | 示例 |
|------|----------|------|
| 大小头（变径） | `A1×B1 / A2×B2 − L` | 800×600 / 400×300 − 长500 |
| 方变圆 | `A1×B1 / D − L` | 800×300 / Φ500 − 长500 |
| 四通 | `A1×B1 / A2×B2 / A3×B3 / A4×B4 − L` | 600×300 / 500×300 / 400×300 / 400×300 − 长800 |
| 正三通（蝴蝶/T型） | `A1×B1(主口) / A2×B2 / A3×B3 − R` | 600×300 / 400×300 / 400×300 − R200 |
| 弯头（水平弯） | `A×B − R` | 1000×320 − R200 |

这套写法的逻辑就一句话：**每个口一个规格，谁大谁在前，最后跟上长度或半径。** 不用形容词，不用"变""带""改"，全用数字和符号。车间师傅拿到单子，照着就能排版，不用猜。

对了，变径和方变圆还有个细节：写单时要把"底平/顶平""左平/右平"这种偏中方式写出来，比如"变径_底平+左平"。上次方变圆那篇我们讲过，偏中方式不写，现场就是装不上。这属于录单规范的一部分，别嫌啰嗦。

### 三、为什么录单规范是管理问题，不是技术问题

很多人觉得录单是打字员的活，谁都会。我原来也这么想，直到我们厂统计过一次返工：**因为录单信息不全导致的返工，在全部返工里占着不小的一块**。板切了、焊了、镀了，最后因为"写单的时候少写了一个口"，整节报废。

这不是技术问题，是流程问题。技术问题好解决，流程问题要靠规矩。我们厂的做法三步：

1. **规范写死**——录单方式对照表挂在系统里，选型就按表来，不自由发挥
2. **图示配套**——每个管件样式配图样，录单的看图选，不用背术语
3. **录完自检**——下单前过一遍"口数对不对、大小顺序对不对、长度算没算"

这套东西写进管件排版规范手册，新来的跟单员培训三天就能上手。以前靠老师傅口传，现在靠表。

## 延伸：行业里最贵的一句话是"我以为"

跟同行聊天，大家都抱怨现场安装问题多。但往深里挖，很多"安装问题"的根子在办公室——图纸信息传到下单，丢了一层；下单传到车间，又丢了一层。丢到最后，错全算在安装工头上。

我们厂现在录单统一了口径：**生产系统里的规格栏，永远按"主口→支咀1(大)→支咀2"排**。跟单的小姑娘们不用记那么多术语，照着表选就行。这个习惯养成之后，我最大的感受是：扯皮少了。以前"谁写错谁不认账"，现在有据可查，单子格式统一，对错一眼就能看出来。

行业里很多小厂不是不会做三通，是"说不清楚三通"。一个管子说不清楚，十个、一百个呢？风管这行讲究实在，实在的第一步，就是把每个字都写明白。

## 实操上注意这几条

| 场景 | 记牢 |
|------|------|
| 录三通 | 主口(或上口)写第一位，支咀大的在前 |
| 录侧三通 | 别忘"顶口"，跟正三通不一样 |
| 圆管件 | 规格里标 [ +2 ]：口径调整量，直口不调、活法兰/点焊 +2、满焊 +4 |
| 算长度 | 方四通=支咀1(大)+600，圆四通十字=支咀1(大)+1200 |
| 写规格 | 一个口一段规格，符号隔开，别用形容词 |
| 变径/方变圆 | 把"底平/顶平、左平/右平"写出来 |
| 下单前 | 过三关：口数对不对、顺序对不对、长度算了没 |

## 结尾

老周现在拿到单子，先看口数齐不齐，齐了才上机。跟单的小姑娘也养成了习惯，录完单自己先念一遍"主口、大支咀、小支咀"，念着不对劲就知道写错了。

录单这十分钟，省下的可能是车间一整天。这买卖，划算。
