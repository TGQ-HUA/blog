上个月月度复盘，我把《常见错误手册》从头翻到尾。这本手册 2025 年 5 月开记，记到 2026 年 8 月，十六个月，61 条。翻完我在办公室坐了一会儿，不是嫌多，是分布跟我原来想的不一样。

## 先把 61 条摊开

手册按管件类型分了十类，每一类都记着日期、项目、出错原因和改法。按出错次数排是这样：

| 管件类型 | 出错次数 |
|------|------|
| 方变圆 | 9 |
| 弯头 / 任意弯 | 8 |
| 短直管 / 短直管堵 | 6 |
| 大小头 / 变径 | 4 |
| 圆管类（圆直管、圆弯头、圆三通） | 4 |
| 折件 / 盆型折件 | 3 |
| S弯 / 方S弯 | 3 |
| 复合风管变径 | 3 |
| 消声器 | 2 |
| 静压箱 | 1 |
| 其他杂项（接油盆、套管、沉水弯、烟罩等） | 18 |

单看这张表，结论很清楚：方变圆最容易错，弯头排第二。照这个思路做一份方变圆检查清单，事情就算办完了。

可我把每一类后面记的损耗金额拉出来一排，顺序全变了。

## 错得多和亏得多，是两笔账

按损失金额排，排第一的是圆管类，占全部损耗的四分之一还多，可它只错了 4 次。方变圆错了 9 次，次数第一，金额排到第五。

为什么差这么多，翻条目就明白了。

方变圆错得密，错的地方也集中：偏移方向做反、该打孔没打、加了棉厚尺寸没跟着改。这类件本身不算贵，做错主要费工时，重做一件的代价有限。

圆管类出错少，但每一件都值钱。手册里那 4 条，两条是手工输入出的问题（直径当成长度输、开平尺寸 1000 少写一个 0），一条是漏看图，还有一条是支管偏移方向弄反，开口方向整个不对。圆管单件价高，尺寸一错就是整件报废。

按 GB50243-2016 的成品要求，外边长 300mm 以上的风管，允许偏差只有 3mm。方向错、口径反，差的可不止 3 毫米，到了现场就是装不上。所以这两笔账得分开算：次数高的地方要立检查清单，金额高的地方要设门槛，贵件的活宁可多一个人过一遍。

## 真正的大头，是同一个动作

手册最后一部分，把 61 条里的改进措施按主题归了类。排第一的是一件事：参图核对，出现二十多次，占了三分之一。

我原以为错在“看不懂图”，翻完发现不是。这二十多条里，没有一条是看不懂，全是没看：

- 一张单上贴了两张图，只看了一张
- 有高偏移又有宽偏移，只看了一个面
- 只看主体尺寸，没看订单备注里的打孔要求
- 参图写着方向，凭“常规”做成了另一个方向

这些错的性质是一样的：判断本身没错，是根本没拿到那个信息，就动手排了。它也是所有错里最容易防的，不用学新东西，不用添设备，把图看全就行。

所以我们现在排参图件有个硬要求：图先打出来，摆在手边，一个数据划一个勾。屏幕上翻来翻去，看漏的概率比纸大得多。

## 手工输入的五个固定套路

61 条里另有一大块出在手指头上，也就是手工排版和手动改尺寸。这些错看着五花八门，归起来只有五个套路：

1. 数字少输或多输：1000 输成 100
2. 长宽搞反：折件、方变圆
3. 直径和长度输反：圆管
4. 方向搞反：水平弯与立弯、大面偏与小面爬、高偏移与宽偏移
5. 接口类型选错：直_25 选成堵_25

五条里有四条是“两个数看着差不多”，一条是“两个选项挨着”。防法也简单：手工输入的东西，输完别急着点确定，回订单上把两个数一一对一遍。

## 延伸：小厂为什么不愿意记这个

把出错记下来，等于把把柄留在纸面上。小厂最怕两件事，一是丢面子，二是被客户看到。

所以我们记的时候守了两条：记录只在技术部内部走，月度复盘只讲事不讲人；手册里写的是“哪类件、哪种错、怎么改”，不写“谁干的”。

记到第四个月，我发现技术部的话变少了。以前车间出个问题，第一句是问“谁排的”，现在第一句是问“哪一类，手册里有没有”。争的不再是人，是那张表。

有同行问过我，记这个值不值。我说看你怎么用。只当考勤本，那是给自己找麻烦；当错题集，它就是最便宜的师傅。

## 实操：五类高频错，对应五个动作

| 高频错 | 出在哪 | 现场动作 |
|------|------|------|
| 偏移方向做反 | 方变圆、任意弯、复合变径 | 方向读一遍，再与参图逐字对一遍 |
| 参图漏看 | 所有带参图的件 | 图打出来，一个数据划一个勾 |
| 直径 / 长度输反 | 圆管、圆弯头 | 手工输入后回订单对两个数 |
| 长宽搞反 | 折件、平板、方变圆 | 先看标注方向再输尺寸 |
| 接口 / 堵选错 | 变径过短的特殊处理 | 特殊处理项单独列一行核对 |

## 最后

手册我每月复盘都要翻一次。上个月翻完，我在扉页上补了一行字：先看分布，再看条目。

小周前两天排一件带参图的方变圆，把图打出来摊在键盘旁边，一个一个对。排完他说了句，图放在眼睛底下，想漏都难。这话比我写的三十页检查清单管用。
