上周三下午，做单的岗位上传过来一张单子，跟单的小姑娘站在旁边，脸色不太好看。

“这个件客户写的是宽 500 乘高 200，你怎么填成 200 乘 500 了？”

“S 弯不是要翻一下吗？弯头也翻的。”

“那你翻的是 S 弯那只，还是翻的弯头那只？”

两个人对着屏幕，同一张客户单，同一只件，一个写的宽高跟另一个是反的。

我在旁边听了一会儿没吭声。这种争论，技术部一个月能碰上两三回。问题不在谁对谁错，在于我们那本防火板的做单说明，早几年是一大篇从头排到尾的，新人翻到哪算哪，翻到弯头就按弯头翻，翻到 S 弯又得重新想一遍。

## 防火板 S 弯就两种，先进对门

按指导书，防火板 S 弯分偏差和高差两类，报价的说法也不一样：

| 类型 | 偏移方向 | 客户报的格式 |
|------|---------|-------------|
| 偏差 S 弯 | 左右偏 | (宽\*高) 长-偏差 |
| 高差 S 弯 | 上下高差 | (高\*宽)\*长-高差 |

看清第二行。高差 S 弯客户报的时候，宽高本身就是倒着写的。所以跟单抄原话没错，做单照着原话直接填就错了。

## 宽高为什么非得翻

指导书里只写了一句话：类似弯头，需翻转口径。为什么翻，书里没解释。

我自己的理解是这样：客户是站在管口那一面报尺寸的，我们做单是站在板面展开那一面填的，两个视角差着 90 度，所以同一个件，报出来的宽高顺序天生是反的。这个解释对不对，我不敢说死，毕竟当年定这条规矩的师傅没留下推导过程。

但做法是统一的。一只客户报“宽500\*高200—长700—偏300—2节”的偏差 S 弯，做单和排版尺寸标注上写的是：

```
宽——200   高——500   长——700
下直位-200  上直位-100  偏——300
编号：F3   数量：2   成型方式：弧形
接口：外置-外尺   材质/料厚：双彩/8   接缝：4条
```

宽 200 高 500，跟客户那张单是反的。做单的人看见这一行，第一件事就是拿客户原话对着核一遍宽高，这个动作不能省。

## 偏和长，不是一回事

客户那句话里最容易含糊的是“偏 300”。

长 700 是这个件在系统里占的长度，偏 300 是它往旁边挪了多少，两个数不是一码事。师傅在现场量开口位置，量的是偏；车间下料，用的是长。单子上少填一个偏，车间做出来的就是一只直的短节，装上去对不上孔。

还有两头那点直段。上直位 100、下直位 200，看着像是排版时随手留的，其实有硬要求：接口直位不能小于 50。这是翻边咬口要用的量，直位留不够，翻边翻不出来，法兰口那一圈就是废的。

## 面积两个算法，我们只报一种

指导书给了两种算法。

分件算，把顶底板和侧板分开按长宽算：

```
S顶 = (宽+偏) × 长，两块
S侧 = 高 × (长+偏)，两块
```

中心线法，(宽+高)×2×中心线，一笔带过。

我拿那只 200×500、长700、偏300 的件两个都代进去算过：分件算出来 1.70 平方，中心线法按中心线取长加偏，算出来 1.40 平方。差 0.3 个平方，两成多。

以前车间和技术部各用一种，同一个件，两个人报出的面积能差两成，客户拿着两张单子比价，还要问我们到底哪个准。后来定下来：报面积统一走分件算。分件算是把四块板分开算的，跟车间实际拼板的路子对得上，客户要对账也说得清。

## 一只 S 弯，做单要看这几栏

| 栏位 | 怎么填 | 常错在哪 |
|------|-------|---------|
| 名称与类型 | 偏差 S 弯 / 高差 S 弯 | 两个类型混填，宽高顺序跟着错 |
| 规格(大头) | 200x500（翻转后的宽高） | 照客户原话填成 500x200 |
| 长度 / 偏差 | 长 700，偏 300 | 只填长不填偏 |
| 上下直位 | 下 200、上 100，接口直位≥50 | 直位压到 50 以下 |
| 成型方式 | 菱形为常规，弧形要写明 | 弧形不写，车间按菱形做 |
| 材质/料厚 | 双彩/8，按客户实际要求 | 漏填，车间默认按 8 走 |
| 接口 / 接缝 | 外置-外尺，接缝 4 条 | 接口形式漏填 |
| 面积 | 分件算，1.70 平方/只 | 用中心线法，报少两成 |

## 延伸

防火板那一章原来是一整篇，直管、S 弯、四通、做单算量全堆在一起，一页翻下去七八个主题。去年技术部把它按管件拆开了，一只管件一页，S 弯单独一页，做单的岗位照着填就行，不用在一大篇里找。

拆的时候有人问过，拆这么细值不值。我觉得值。文档不是写给写的人看的，是写给夜里加班、只扫一眼就要填单的人看的。他找得到，规矩才落得下去。

那天的争论最后是这么收的：做单的师傅对，跟单的小姑娘也没错，她照客户原话抄的。现在的单子上，客户原话照抄一行，底下一行写做单尺寸，两行都在，谁也不用再翻旧账。

有同行问我防火板 S 弯怎么跟新人讲，我就让他先看这两行字：客户报的宽高，做单要翻过来。剩下的，一页纸够了。
