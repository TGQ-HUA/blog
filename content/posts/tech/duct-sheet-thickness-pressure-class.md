昨天上午，跟单部的小妹把手机递到我面前。客户的原话是："1000×500 的风管，中压，先来 20 节，镀锌的。"

小妹说，这话没毛病吧，长度没给，我按 2 米一节报的。

长度不用猜。麻烦的是这三句话里，板厚一个字没提。我把 1000 拿过来，先问一句：这是外边长吧？客户说是。我又问压力，客户愣了，说系统是排烟的，风机那台是老设备，具体多少帕他也不知道。

这就不能照着"通风管"三个字下料了。同样是 1000 的长边，走通风和走排烟，板厚不是一回事。

## 板厚的入口是两个数，不是尺寸一个数

很多人以为板厚是按尺寸选的。尺寸只是其中一半，另一半是这套系统的压力等级。两本国标给的表是一样的口径：

GB50243-2016 第 4.2.3 条和 JGJ141-2017 第 4.2 节，矩形镀锌钢板风管按长边尺寸和压力等级查板厚（单位 mm）：

| 长边 b (mm) | 低压 P≤500Pa | 中压 500<P≤1500Pa | 高压 P>1500Pa |
|-------------|:---:|:---:|:---:|
| b ≤ 320 | 0.50 | 0.50 | 0.75 |
| 320 < b ≤ 450 | 0.50 | 0.60 | 0.75 |
| 450 < b ≤ 630 | 0.60 | 0.75 | 0.75 |
| 630 < b ≤ 1000 | 0.75 | 0.75 | 1.00 |
| 1000 < b ≤ 1250 | 0.75 | 1.00 | 1.00 |
| 1250 < b ≤ 2000 | 1.00 | 1.00 | 1.20 |
| 2000 < b ≤ 4000 | 1.20 | 1.20 | 按设计 |

拿客户那单说：长边 1000，走通风（低压）是 0.75，走排烟（P>1500 算高压）是 1.00。尺寸一个字没变，板厚差一档。

表里还有一条容易被忽略的：**长边 1000 和长边 1100，就差 100 毫米，中压这个区间从 0.75 跳到 1.00。**所以接到单子，长边的数要精确，别自己四舍五入。

顺便说一句，板厚这件事在验收里不是小事。GB50243-2016 第 4.2.2 条是强条，材料品种、规格、性能和厚度不符合设计要求和标准规定，判定是整个批次不合格。图纸上要 1.0 的料，我们自己"看着差不多"改成 0.75，验收这一步就过不去。

## 两张国标表，有一格对不上

上面那张表我是照 JGJ141-2017 抄的。GB50243-2016 那张表跟它高度一致，只有一格不一样：**320 < b ≤ 450 的低压系统，GB50243 给的是 0.60，JGJ141 给的是 0.50。**

我们不自己定，就按 0.50 走（这段是低压小尺寸，用 0.5 的料常年做下来没问题）。但接单的时候我会多问一句：这套系统验收按哪本走。写清楚，省得工地把两本规范摊开在那儿争。

排烟系统还有一条硬杠：GB50243-2016 第 4.2.5 条说的是防火风管的本体、框架、固定材料和密封垫料必须是不燃材料，耐火极限按设计。所以"排烟风管"这四个字，牵出来的不只是板厚。

## 圆管不是"减薄一级"就完事

JGJ141-2017 里有一句话：圆形风管受力均匀，同压力条件下壁厚可比矩形减薄一级。这话没错，但只说了正压那一半。

我们厂内部的圆形板厚表是分正压和负压的。以 450 < D ≤ 630 这一段为例：

| 压力类别 | 板厚 (mm) |
|----------|:---:|
| 微压 / 低压 | 0.60 |
| 中压（正压） | 0.60 |
| 高压（正压） | 0.75 |
| 中压（负压） | 0.75 |
| 高压（负压） | 1.00 |

同一根 630 的圆管，送风侧用 0.6 能过，回风侧就得 0.75。道理不复杂：正压的时候板是往外顶，圆管环向受力最均匀，越圆越结实；负压是往里吸，板受的是往里凹的压力，一失稳就是整段瘪下去，凹进去容易、弹不回来。所以负压管比正压厚一档，这是照着受力方向来的，不算保守。

有人问过，板厚不够拿加固凑行不行。加固解决的是振动和噪声，是另一笔账——JGJ141-2017 第 4.6 节把加固起点写得很明确：矩形风管低压超 630、中压超 500、高压超 400 就要加固，圆管是低压超 800、中压超 630、高压超 500。板厚不足用加固补，等于把结构问题当噪声问题处理，两个账混着一个账算。

## 材质那一栏，也别只写"镀锌"两个字

板厚定了，材质还得说清。厂里常用的这几种，写法不一样，价也不一样：

| 材质 | 要点 |
|------|------|
| 镀锌板（有花） | 锌层 40G，车间常规有料 |
| 镀锌板（无花） | 锌层 40G / 80G / 120G，接单先确认车间库存 |
| 武钢板 | 只有无花，80G / 120G 两种 |
| 不锈钢 201# | 含锰高，Cr 约 15%、Ni 约 5%，表面发暗，潮的地方会锈 |
| 不锈钢 304# | Cr 约 18%、Ni 约 9%，哑光，不生锈 |
| 碳钢冷板 | 2.0mm 以内，走冷折弯；除尘系统用 2.0 / 3.0 |
| 防火板 | 8 / 14 / 20mm 三种厚度，彩钢面分单彩、双彩、白板 |

不锈钢有一条修正规则在 JGJ141-2017 第 4.1.1 节：厚度 ≥ 1.0mm 时可比同规格镀锌板减薄 0.1~0.2mm；铝板反过来，要加厚 0.1~0.2mm。这条要是不清楚，料不是报虚了，就是亏在里头。

防火板更简单，按耐火极限直接对：0.5H 用 8mm 单彩或双彩，1.0H 用 14mm，2.0H 是内层 0.75 镀锌板加 50 厚防火棉再贴 8mm 板，3.0H 是内 1.0 镀锌板加 100 厚防火棉加外层 0.75 镀锌板。客户说"要防火 1 小时的"，你要是不问这一句，做出来的是 8mm 那档，等于没做。

## 最贵的一个坑：内尺寸还是外尺寸

金属风管的尺寸是外边长、外径，这个大家熟。防火板反过来，宜用内边长、内径。

问题出在传话。装的人张口说"内尺寸 750×450"，你没多问一句就下了料，做出来的管子比洞口小两个板厚，现场塞不进去。8mm 的板，内尺寸 750×450 要按 766×466 排，接缝那边公口还得减一个料厚。

我们厂防火板还有个缩尺：8mm 板缩 -9，14mm 单彩缩 -15.5，14mm 双彩缩 -16.5，20mm 缩 -21。这些值不写进单子，排版的人光看尺寸猜不出来。

尺寸口径一错，后面全是连锁反应：料算多了，或者现场装不上返工重做。这活没有中间状态。

## 延伸：为什么这张表老是被跳过

板厚这东西，看不见摸不着，验收之前没人提它。单子上"通风管"三个字一写，接单的觉得交代清楚了，车间拿着就下料。等到打压漏风、或者监理翻出 GB50243 第 4.2.2 来对板厚，才发现当初那几句话没问。

更现实的一层是钱。薄一档料，一平米省不了多少，但一个项目几千米，累积起来是笔真金白银。所以有人愿意赌——赌甲方不查、监理不翻规范、负压侧不瘪。赌输一回，返工的钱够薄板省好几年的。

同行里做得稳的厂，做法其实很土：把压力等级、系统用途、材质、尺寸口径四栏做成录单的必填项，师傅手上有数，不用回头问。这跟用什么软件没关系，关键是把该问的问在前面。

## 实操：接单先问清这四条

| 要问的 | 问不清会怎样 |
|--------|--------------|
| **走什么系统**：通风、空调、排烟、净化除尘 | 排烟当通风报，板厚少一档，强条也过不去 |
| **压力等级**：低压 / 中压 / 高压，正压还是负压 | 圆管负压侧会瘪，矩形中压侧鼓包 |
| **尺寸口径**：外边长 / 外径，还是内边长 / 内径 | 防火板小两个板厚，现场装不进去 |
| **材质**：镀锌有花无花、不锈钢 201 还是 304、防火板板厚与彩面 | 无花板没库存，1.0H 的活做成 8mm |

单子上写清楚是这样一行：排烟、高压、1250×500 外边长、镀锌无花、板厚 1.2。

## 结尾

客户那单排烟管，最后是 1.0 的料下去的。小妹现在接电话有个习惯，尺寸报完会追问三句：什么系统、压力多大、外面还是里面。

她说这三句问着烦，但吃过一回亏就记住了。有一批防火板，接的是"内尺寸"，我们按外尺寸下了料，做完拉到现场，一节也装不上，整批退回重做。问三句，比整批退回便宜。
