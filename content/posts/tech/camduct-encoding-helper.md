车间做 CAMduct 排料，每次都要：复制编码 → 手动改材质 → 改接口 → 选图库 → 启动 CAMduct → 点预设 → 创建新文档 → 存盘。一套下来半分钟，一天几十次就是半小时，步骤一多还容易漏，漏了就得返工。

这个小工具把它压成两次点击：读剪贴板 → 执行操作，剩下的交给它自动跑完。下面是完整的使用说明。

> **当前版本：V1.2.0.0**（2026-09-24）
> 版本更新记录见文末，每次发版同步更新。

---

## 一、运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 依赖软件 | CAMduct（需已安装且能正常启动） |
| 安装包大小 | 约 3.2 MB |
| 输出目录 | `D:\BM.txt`（程序生成的编码文件） |

---

## 二、安装

1. 双击安装包（文件名形如 `编码处理程序_V1.2.0.0_20260924_170916_Setup.exe`）
2. 若检测到程序正在运行，会提示关闭——选「是」自动关闭后继续
3. 按提示下一步，安装目录默认 `C:\Program Files\编码处理程序`
4. 可勾选「创建桌面快捷方式」
5. **安装完成后会自动打开本使用说明页面**

安装程序只覆盖程序文件本身，不会动你已有的配置和授权信息。

---

## 三、首次使用：设备绑定

程序绑定运行设备，防止随意拷贝到别的电脑。

1. 首次启动会弹出验证窗口，标题为「首次使用 - 绑定设备」
2. 窗口左侧显示本机的**硬件标识**（这台电脑的唯一码）
3. 把这个硬件标识发给工具维护人，换取两样东西：
   - **固定密码**
   - **绑定密钥**（与本机硬件标识一一对应）
4. 把密码填入「固定密码」框、绑定密钥填入「绑定密钥」框 → 点「确定」
5. 验证通过后自动完成绑定，以后启动直接进主界面

> ⚠️ 绑定信息保存在安装目录的 `security.ini`，请不要删除或修改。更换电脑需要重新走一次绑定流程；检测到设备变更时会出现「设备变更验证」窗口。

---

## 四、界面速览

主窗口分六个区，从上到下：

| 区域 | 内容 | 说明 |
|------|------|------|
| 材质处理 | 材质下拉框 + 增删按钮 | 编码里的"对应材质"会替换成这里选的值 |
| 工艺处理 | 压筋方式下拉框 + 增删按钮 | 编码里的"是否压筋"替换成这里选的值 |
| 名称设置 | 项目命名 / 标签字符 | 项目命名自动从编码里提取客户信息 |
| 接口调整 | 接口替换开关 + 原始/目标接口 + 共板打孔规则 | 共板法兰接口批量互换 |
| 软件设置 | 图库选择栏 + CAMduct 路径 + 开机自启 | 图库对应 CAMduct 里的预设名 |
| 启动设置 | 个人简称、执行按钮 | 个人简称会写进编码的地址栏 |

底部两个按钮：**「读取剪切板内容」** 载入编码，**「执行操作」** 一键跑完流程。右上角「选项管理」可集中维护所有下拉列表。

## 五、日常操作流程

1. 在 CAMduct 里选中编码行，`Ctrl+C` 复制
2. 切到编码处理助手，点 **「读取剪切板内容」**
   - 程序自动提取项目名称、修正非法字符、填入「项目命名」
3. 确认（或调整）材质、工艺、图库三项
4. 点 **「执行操作」**
5. 进度条自动走完，全程不用再动鼠标

程序会依次完成：处理编码 → 生成 `D:\BM.txt` → 启动 CAMduct → 选中指定预设 → 创建新文档 → 展开文件菜单 → 保存文件。

> 执行过程中键盘鼠标会被临时锁定，防止误触打断流程，属正常现象。

## 六、功能详解

### 1. 编码自动处理

从剪贴板读入的编码行会做这几件事：

- **材质替换**：编码里的"对应材质"→ 你选的角铁材质
- **工艺处理**：编码里的"是否压筋"→ 你选的压筋规则
- **接口替换**：支持共板法兰接口批量互换（固定首孔 ↔ 整边均分）；涉及"Z共板"时会弹窗提示替换了几个
- **项目命名**：自动从编码的客户地址段提取，并按文件名规范修正非法字符（非法符号替换为下划线，去掉结尾的点）
- **图库前缀**：按图库类型自动加 `[咬口]`/`[焊接]`/`[防火]`/`[消音]` 等标记
- **公司地址**：把「个人简称」写入编码的地址段

处理结果写到 `D:\BM.txt`，CAMduct 导入即可。

### 2. 全自动 CAMduct 流程

点「执行操作」后自动完成：

1. 启动 CAMduct（带 `/L=ChineseTraditional` 参数）
2. 在预设列表里选中「图库选择栏」指定的预设
3. 点击「创建新文档」
4. 展开文件菜单 → 另存为
5. 定位到 `D:\` → 文件名填 `BM.txt` → 确定

### 3. 悬浮窗模式

主窗口点 × 不退出，缩成屏幕上的一个圆形小图标：

- **单击** → 恢复主窗口
- **拖动** → 挪位置（位置自动记住）
- **右键** → 菜单里选「退出程序」

悬浮窗始终置顶，不占任务栏，随叫随到。

### 4. 开机自启

勾选「开机时自动启动」，系统开机后自动加载。配合悬浮窗模式，开机就在屏幕上等着。

### 5. 选项管理

点「选项管理」打开配置窗口，集中维护：

- 材质列表
- 工艺（压筋）列表
- 图库列表
- 原始接口 / 目标接口列表（分「固定首孔」「整边均分」两组）

所有数据保存在安装目录的 `编码导入数据.ini`，重启不丢。

## 七、常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 提示"请复制正确的编码行！日期项异常" | 剪贴板内容里没有 `JOBHEADER_START` 标记，说明复制的不是完整编码行 |
| 提示"未找到 CAMduct 窗口" | 软件设置里的 CAMduct 路径不对，点「选择软件路径栏」重新指定 `CAMduct.exe` |
| 提示"未找到预设：xxx" | 图库选择栏里的名称要和 CAMduct 预设列表里的名字**完全一致** |
| 提示"处理完成，但无法保存到 D:\BM.txt" | `D:\` 盘不存在或不可写；程序会把处理结果放到剪贴板作为备用 |
| 执行到一半卡住 | 程序会锁定键鼠，等进度条走完；若长时间无响应，检查 CAMduct 是否弹了额外对话框 |
| 换电脑后提示设备变更 | 需要重新获取绑定密钥，流程同首次绑定 |
| 忘记密码 | 联系工具维护人 |
