上周技术部想把那张老 Excel 搬到网页上。

表在我来之前就有了，一列填尺寸，后面单价、面积、成本全自动算。跟单员在电脑上用，客户站在车间门口等，要查个规格就再跑一趟办公室。想着搬到网页上，手机打开就能看。

我一开始的判断是界面麻烦。真跑起来才知道，界面是最省事的部分。第一关是公式。

## 先把壳剥掉

用脚本把 xlsx 拆开看，全表 10677 条公式。其中 1744 条长这样：

```
=_xlfn.LET(_xlpm.内CZ,D874,…)
```

`_xlfn.` 是 Excel 存新版函数时加的标记，`_xlpm.` 是 LET 里变量的标记。另外还有 215 处 `_wpsfn.REGEXP`，那是 WPS 自己的私有写法，`_xleta.CONCAT`、`xlws.FILTER` 也都见过。

打个比方，这像写作文时把每个成语都标上拼音和出处，自家软件看得懂，换个引擎就不认。得先剥掉前缀，再改写成老写法：LET 里的变量一个个代进去展开，IFS 变成一层套一层的 IF。全是机械替换，不算出别的结果。

剥完自检：10677 条公式，括号 0 条不平衡，前缀残留 0 条。

## 定义名称，报出来的数会骗人

第二个坑更阴。表里有一堆定义名称，比如"税率""工厂M"这种。Python 的 openpyxl 读出来只有 3 个，我一开始就按 3 个处理了。

后来直接翻 `xl/workbook.xml`，里面实际有 15 个。少的那 12 个（PMC.COD、shuibi、FP、YFEI、LIT 这些）挂在某张表下面，是表级名称，接口不报。

后果不是"少点东西"，是 AF6 那个全局系数变成 #NAME?，然后单价、合价两整列全崩。像家里的总闸没合上，你挨个房间查灯泡。

规矩只有一条：迁移前先把定义名称总数数一遍，接口给的数当参考，别当结论。

## Excel 显示得对，不等于公式是对的

第三关是这张表本身有伤。

有一格引用了一个叫 YWD 的名称。我在整本工作簿里搜，YWD 出现 0 次，没有任何定义名称叫这个。也就是说这格本该报错，但 Excel 上显示 1，一直没出过事，因为它拿旧缓存撑着，你不碰它，它就不重算。

按常量处理后，全表重算的正确率从 92.59% 上到 97.44%，单价列更夸张，30.72% 到 97.59%。

有个结论我记在本子上了：做新旧对照时，如果出现"Excel 算得对、新引擎算错了"，先怀疑那条公式本身有悬空引用，别急着怪引擎。老表里这种靠缓存活着的格子，比想象中多。

## 三个补不上的缺口

最后剩下的 3% 不是懒，是真补不上。

数组公式，全表 815 个锚点。Python 读出来不是字符串，是个对象，不取 `.text` 直接写进去就是一堆垃圾。宏函数，表里有几个 VB 宏算出来的值，网页端没有那个宏，只能把结果固化下来。动态数组溢出，一格算出好几个值往外铺，快照搬不过去。

还有两个坑跟引擎无关。文本型数字，编号列的 `'031001500000'` 不标类型就变成 `31001500000`，前导 0 丢了，整列编号全错。另一个是取值时机，表里有 9621 条重公式，我等 1.2 秒去取快照，拿回来全是 null，得等引擎自己回调算完。

## 实测的最后一步

拿真表逐格对照。9262 个有基准的格，9025 个对上，97.44%。再挑 50 个人工会看的关键格，47 个对。剩下 3 个里 1 个宏函数、2 个动态数组溢出，正是上面说的缺口。把这两类剔掉，47 个对 47 个。

有人问我从 Excel 搬网页版最难的是哪一步，我把踩过的地方列成几行：

| 你看到的 | 实际是什么 | 怎么办 |
|---|---|---|
| 公式写得挺干净 | 带着 `_xlfn.` `_xlpm.` `_wpsfn.` 前缀 | 剥前缀，LET 展开，IFS 转嵌套 IF |
| 定义名称读出 3 个 | 表级名称没报，实际 15 个 | 直接读 `workbook.xml` 数总数 |
| Excel 显示 1，没报错 | 可能靠旧缓存撑着，公式有悬空引用 | 重算一遍再看，别信缓存 |
| 一格一个数 | 可能是数组公式，读出的是对象不是字符串 | 取 `.text`，别直接转字符串 |
| 编号 `031001500000` | 不标类型就是数字，前导 0 丢 | 常量写入时带类型标记 |
| 等 1.2 秒就能取结果 | 大表算得慢，取回来全是 null | 等引擎的算完回调，别拍脑袋估时间 |

## 一点延伸

厂里这些 Excel，是十几年攒下来的工艺口径。公式里藏的不是数学，是经验：什么规格该加厚，缩尺缩多少，接口直位留多少。搬系统这活，一半是做界面，一半是把这些口径翻译成程序能读的话。

翻译最怕"看着都对"。所以我最后一定要做逐格对照，97% 这个数不好看，可它告诉我剩下那 3% 在哪。要是没有这个数，我大概会以为搬完了。

现在那张表在网页上能跑，跟单员不用再跑回办公室。老 Excel 我没删，留着当尺子，每次改动都拿它核一遍，后面又靠它翻出两处差异。
