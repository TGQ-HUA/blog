## 引子：一张废了的板子

上周二排版的小周报了个弯头，500×200，R 填了 80。下料下出来，内弧板就巴掌宽，滚圆机一压全是褶，咬口死活对不上。老师傅过来看了一眼："R 小于 100 要做内直角，你按内弧下的料，不废才怪。"

一张镀锌板，白瞎了。

其实不怪小周。客户单子上就写"90°弯头 500×200"，R 没人告诉他怎么定。排版软件里 R 是个框，填什么，靠猜。

## 正文：弯头的R，到底谁说了算

### 先搞清楚弯头是几片做的

矩形弯头不是一根弯管子，是 4 片板拼的：扇形顶板、底板、内外弧板。我们厂管这个叫"4 片下料"。

R 就是弯头的曲率半径，它决定这 4 片板的形状。R 大，弯得缓，弧板宽；R 小，弯得急，弧板窄。客户单子上不写 R 的，我们默认 200，不写角度的默认 90°。

R 看着是个小参数，实际是弯头的骨架。定错了，后面全是废活。

### 三种样式，一种比一种"将就"

弯头内边有三种做法：

- **内弧形**：内外同心弧，气流最顺，阻力最小，国标推荐的做法
- **内菱角**：内边不是弧，是两段折线，中间带个小菱角
- **内直角**：内边直接直角

为什么不能全做内弧形？因为弧板太窄或太宽都滚不出来。内弧板滚圆是有极限的：板太窄，滚圆机一压就皱；板太宽，弧板超过 1400mm，滚圆机根本滚不动。

所以厂里规则是这样定的（管件排版规范 B.02.01）：

| 情况 | 样式 |
|------|------|
| 弧板宽度 > 1400mm | 内菱角 |
| R < 150（不含直位） | 内菱角 |
| R < 100（不含直位） | 内直角 |
| R 直角 < 50 | 改做 50 |

小周填的 R=80，小于 100，该做内直角，他按内弧下了料，内弧板太窄，滚圆起皱，废了。

### 变径弯头，坑更多

弯头两头一样高，叫等高弯头。两头不一样高，叫变径弯头（不等高）。变径弯头有专门规矩：

- 高差 ≤ 100：做内弧形
- 高差 > 100：做内菱角（直位 50，内弧 R-50）
- **变径弯头不能做内直角，也不能做外直角**

我们以前干过一件蠢事：一个变径弯头，排版的图省事直接上了内直角，结果装到现场，咬口开裂，漏风。直角处应力全集中在那一点，板子薄的根本扛不住。从那以后这条写进规范：变径禁直角。

还有三种情况，弯头必须改成"等高弯头 + 大小头"来做：内外弧板要做超尺寸拼接缝的、弯头带直位的、R 要求直角的。别嫌麻烦，硬做出来的弯头，现场十有八九出问题。

### 国标怎么说

GB50243-2016《通风与空调工程施工质量验收规范》第 4.3.6 条：矩形风管弯管宜采用曲率半径为一个平面边长、内外同心弧的形式；采用其他形式的弯管，且平面边长大于 500mm 时，应设弯管导流片。

翻译一下：国标推荐的弯头，R 取一个平面边长，内外同心弧，就是咱们的内弧形。现场吊顶就那么大点地方，R 全按一个平面边长做，风管装不进去，所以厂里规则是在国标和工艺之间找平衡：能做内弧就做内弧，做不了才降级成内菱角、内直角。但注意，一旦用了非同心弧的形式，平面边长超过 500mm，国标就要求加导流片，导流片的做法在管件排版规范 B.07 里。别省这玩意，直角弯没导流片，风噪和阻力都上来了，验收的时候也容易被挑出来。

同一条规范第 4.3.7 条还规定：风管变径管单面变径夹角不宜大于 30°，双面变径夹角不宜大于 60°。变径弯头高差太大，夹角超了，气流在弯头里打架，风噪大、阻力大。高差超过 100 就改内菱角，也是在控制这个夹角。

## 延伸：R 这个参数，行业里没人管

弯头 R 是个有意思的参数：设计院图纸上一般不写，客户单子上一般不写，最后全压在排版师傅身上。老师傅凭感觉填，新来的照葫芦画瓢，同一批弯头，两个师傅能排出两种 R。

这不是师傅的问题，是规则没落地。小厂弯头样式全靠师傅脑子里的经验，人一走，经验就没了。我们把规则定成表，贴在排版工位上，谁来了都能查。

风管这行，很多东西看着是"经验"，拆开看都是"规律"。经验装在人脑子里，规律写在纸上。这行想往系统上靠，就得先把老师傅脑子里的规律一条条挖出来。

## 实操：有同行问我弯头样式怎么定

就一张表，打印出来贴排版电脑旁边：

| 情况 | 样式 | 原因 |
|------|------|------|
| 弧板宽度 > 1400mm | 内菱角 | 弧板太长，滚圆机滚不动 |
| R < 150（不含直位） | 内菱角 | 内弧与直位均分 |
| R < 100（不含直位） | 内直角 | 内弧板太窄，滚圆起皱 |
| R 直角 < 50 | 改做 50 | 弯头 < 90° 时两端直位 < 50 也按 50 |
| 变径，高差 ≤ 100 | 内弧形 | — |
| 变径，高差 > 100 | 内菱角（直位 50，内弧 R-50） | — |
| 变径（任何高差） | 禁做内直角/外直角 | 应力集中，咬口开裂 |

再记三条"必须改成等高+大小头"的：内外弧板要超尺寸拼接缝的、带直位的、R 要直角的。单子上没写 R 的，默认 200。做单的时候分清水平弯和立弯，水平弯写宽×高，立弯写高×宽，别写反了。
