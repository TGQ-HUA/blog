## 引子：现场试机，风量不对

上礼拜工程部打电话来：某工地试机，末端风量差得离谱，怀疑风管做错了。技术部的人跑过去一看，风管没做错，是变径管的问题——800×400 变 500×320，做单的人图省事，长度只给了 300。变径段又短又陡，风走到那里直接"打架"，一路乱流冲到末端，风量能不少吗。

客户单子上就写"变径 800×400 变 500×320"，长度没人规定。排版师傅凭感觉填，填短了，返工的是车间，背锅的是技术部。

## 正文：变径管看着简单，三个坑都是真金白银换的

### 先说清楚大小头是什么

大小头就是变径管，连接两种不同尺寸风管的过渡段。一张图纸上最不起眼的管件，却是最容易出问题的一个。

做大小头，第一件事不是算尺寸，是定"偏法"——大小头两端的中心怎么对齐（管件排版规范手册 B.04.01）：

| 形态 | 含义 | 什么时候用 |
|------|------|-----------|
| **对中** | 左右对中（宽）、上下对中（高）、全对中 | 两头居中对齐，标准做法 |
| **平边** | 左平/右平（边平）、顶平/底平（面平） | 贴梁贴墙走、要留安装空间时 |
| **偏差** | 左右偏移、上下高差 | 现场避让障碍物 |

这个偏法，图纸上一般不画，客户电话里才说一句"贴梁底走"。做单的没问清，按对中做了，现场一装，底面差一截，接不上，整节返工。我们以前干过这蠢事，后来做单规范里加了一条：变径必须确认偏法，没写明的默认对中，但贴梁贴墙的活要先问一句。

### 第二个坑：变径段做太短，角度太陡

这是最容易被忽视的一条。变径的"陡峭程度"是有标准的，JGJ141-2017《通风管道技术规程》第 6.2.2 条给了明确角度：

| 变径方向 | 推荐角度 | 最大角度 |
|---------|---------|---------|
| 扩散（小变大） | ≤ 15° | ≤ 30° |
| 收缩（大变小） | ≤ 30° | ≤ 60° |

GB50243-2016《通风与空调工程施工质量验收规范》第 4.3.7 条也说：风管变径管单面变径夹角不宜大于 30°，双面变径夹角不宜大于 60°。

翻译成人话：变径不能"猛地一收"。800 变 500，宽差 300，按单面变径夹角 30° 的上限算，变径段至少得 520mm 长；按 JGJ141 推荐的 15° 算，得 1100mm 往上。做得越短，夹角越大，气流在变径里越乱。

我们厂现在的规矩（B.04.01.3）：变径段长度默认给够，比如 500mm 长的变径，如果截面变化太猛，就加长到 1000mm，减缓截面变化梯度。宁可多费半米板，不让现场风量打折扣。

### 第三个坑：偏差过大，中段收缩过猛

变径两端偏移超出合理范围，中段管件会变小，风阻增大，风量减小，直接影响风机效率。这条手册里单独列了警示（B.04.01.3）：

- **加长管件**：增加变径段长度，减缓截面变化梯度
- **检查偏移量**：对中变径两侧偏移量应一致；平边变径一侧为 0、另一侧在设计范围内
- **高度不同时按 S 弯排版**：两端高度不一致（上下偏移），别硬做变径，改用 S 弯（双向偏移）过渡

最后这条我们踩过：一个变径，两端高度差 100 多，做单的硬做变径，结果中段又窄又扭，装上去漏风。后来改成"高差大就上 S 弯"，再没出过这毛病。

### 成型方式：U+I 形还是四片式

定完偏法和长度，才轮到怎么下料。手册 B.04.01.2 的决策规则：

```
第1条 · 先看能不能走 U+I 形
  必须同时满足：
  条件A（尺寸门槛）：半周长 < 2000mm 且 长度 < 1000mm
  条件B（一边平）：底平/顶平 → 宽不变；边平/侧平 → 高不变
  两个条件都满足 → U+I 形

第2条 · 其他一律 4 片式
  尺寸超过门槛（太大/太长）
  或不是一边平的大小头（两边都变径）
```

记不住没关系，做单界面里这个决策是自动的，但排版的人得看得懂为什么：U+I 形省料、好做，但只适合"一边平"的场合；两边都变径的，老老实实四片式。

### 做单和算量，一张单子写清楚

手册 B.04.02 里有标准做单格式，照抄就行：

```
下宽——800  上宽——500  下高——400  上高——320  长——500
下直位-100  上直位-50  宽偏移-对中  高偏移-对中
编号：Z4  成型方式：四片式  数量：2
接口：共板  材质/料厚：镀锌/0.75  接缝：大小边
```

客户表述是"大小头(中变)：上宽800上高400—变下宽500下高320—长500—2节"，翻译成内部单子就是上面那行。面积计算公式：`(下宽 + 下高 + 大小边×2) × 2 × (长 + 接口×2)`，报价、算料都用这个，别自己发明公式，不然跟车间对不上账。

## 延伸：最不起眼的管件，最考验做单的人

变径管在图纸上就那么一小截，设计院不画偏法、不标长度，全压在排版和做单的人身上。老师傅看一眼就知道"这变径太陡了"，新人照单子填，填完就下料。

这不是谁笨，是规矩没落到纸上。我们把这三条写进手册，贴在排版工位上：先问偏法、再算长度、最后定成型。谁来了都能查，不用等师傅带三年才摸到门道。

风管这行，图纸上没写的东西，才是真正要命的东西。我们把这些定成规矩写进手册，就是干这个的。

## 实操：有同行问变径管怎么定规矩

就按这张表来，打印出来贴工位上：

| 项目 | 规矩 | 依据 |
|------|------|------|
| 偏法 | 先确认对中/平边/偏差，没写明默认对中，贴梁贴墙先问一句 | B.04.01.1 |
| 变径长度 | 扩散 ≤15°（最大 30°）、收缩 ≤30°（最大 60°），不够就加长到 1000mm | JGJ141-2017 6.2.2、GB50243-2016 4.3.7 |
| 偏差检查 | 对中两侧偏移一致，平边一侧为 0 | B.04.01.3 |
| 高差大 | 不硬做变径，改 S 弯过渡 | B.04.01.3 |
| 成型方式 | 半周长<2000 且长<1000 且一边平 → U+I；否则四片式 | B.04.01.2 |
| 面积公式 | (下宽+下高+大小边×2)×2×(长+接口×2) | B.04.02 |
