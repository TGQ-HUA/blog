## 引子：一句“来5节”，车间懵了

上周跟单部小姑娘小周拿着一张单子来找我，说客户要"防火板直管 1000×500，来 5 节"。

我一看就问她：长度呢？小周说客户没写长度，就说了句"老规矩"。

我把单子拿给车间师傅看，师傅也愣了半天。防火板直管跟镀锌板直管不一样，没有"默认 1 米"这回事——我们厂的标准节是 **1200**，短节是 **590**。客户嘴里一句"老规矩"，到了车间可能就是两种管子。

这个事让我觉得值得写一篇。防火板这行，做单环节的坑，比车间里的坑多得多。

## 正文：防火板直管做单，规矩在哪儿

先说结论：防火板直管的做单，本质是三件事——**分清类型、定死成型方式、算对面积**。哪一件含糊了，车间就白干。

### 一、标准节和短节，别搞混

| 类型 | 下料方式 | 就料长度 |
|------|----------|----------|
| 标准直管 | 五线开料 | **1200mm** |
| 短直管 | 异形件开料 | **590mm** |

客户表述里有个约定俗成的规矩（我们厂写进了规范，见管件排版规范手册 E.02.01）：

- 客户说"直管 1000×500——5 节"，没写长度 = **标准直管 1200**
- 客户说"直管堵 1000×500——1 节" = **直管带堵头**
- 客户说"短直管 1000×500×400——3 节"，写了长度 = **按实际长度做**

三种说法三种做法，录单的人必须会翻译。我们厂吃过亏：以前有人把"直管堵"理解成"堵头"，单子下错了，板切了没法退。

### 二、长度不是随便定的

防火板是 1200 宽的板，长度上有两个"商榷规则"：

| 客户要的长度 | 我们的处理 | 原因 |
|--------------|-----------|------|
| 600 | 商榷减为 **590**（就料） | 590 是短直管就料长度，不浪费 |
| 1200 | 商榷减为 **1190** | 避免拼板，1190 正好一块板 |
| 与标准节差 ≈10mm | 建议直接做成标准直管 | 省一道异形件工序 |
| 大于 2000 | 拆成「标准直管 + 短直管」 | 超过就料极限 |

这里头有个细节：防火板直管不是越长越好，超过 2000 必须拆。不拆的话，车间就得拼板，拼缝一多，外观和强度都打折。有同行问过我"为什么 1200 要减成 1190"——你想想，一块板正好 1200 宽，你切成 1200 长，四边都要修，一修就小，拼板跑不掉。做成 1190，板都不用拼。

### 三、成型方式：口字、U+I、L、四片

防火板直管不是一块板围起来就完事，按口径大小选成型方式：

| 成型方式 | 条件 | 包角条数 |
|----------|------|:--------:|
| 口字形 | 口径周长 ≤ 2400mm | 1 条 |
| U+I 形 | 三边长之和 ≤ 2400mm | 2 条 |
| L 形 | 两边长之和 ≤ 2400mm | 2 条 |
| 四片式 | 单边长 ≤ 2400mm | 4 条 |

选成型方式的依据是**单块板的极限**：任何一片板的最大尺寸不能超过 2400。口字形一条包角，最省工；口径一大，就得拆成 U+I、L 甚至四片，包角条数跟着涨。做单的时候如果没标成型方式，车间师傅就得自己猜，猜错了返工的是整节管子。

做单示例（我们厂报价单的写法）：

```
宽——1000  高——500  长——400
编号：F1  数量：1  成型方式：U+I形
接口：外置-外尺  材质/料厚：双彩/8  接缝：2条
```

### 四、面积算量：半成品按实际开料算

防火板直管面积公式：

```
(宽 + 高) × 2 × 长
```

注意一个关键点：**半成品按实际开料防火板数量算**，不是按成品表面积。防火板按张算成本，四片式比口字形费料，算量的时候这点必须带进去，不然报价就是亏的。

### 五、缩尺工艺：2025 年起改了规矩

防火板合管有个缩尺问题。以前我们缩的是面板（顶钣/底钣），合管以后折弯缝露在外面，有缝、漏风、不好看。2025 年 9 月 1 日起，我们厂改了工艺（见管件排版规范手册 E.01.02）：

| 项目 | 旧工艺 | 新工艺 |
|------|--------|--------|
| 缩尺对象 | 面板（顶钣/底钣）缩尺 | **侧板**（内弧/外弧）缩尺 |
| 排版接缝 | 公口负尺 | **母口负尺** |
| 合管方式 | 面板嵌入管内 | **侧板嵌入管内** |
| 效果 | 折弯缝裸露 | 折弯缝被面板掩盖 |

一句话：缩尺从面板挪到侧板，接缝被盖住了。这个调整直接影响做单——下单时标注的尺寸基准没变，但师傅合管的方式变了。做单的人要知道这件事，不然跟车间师傅对不上话。

从规范上讲，防火板风管属于非金属风管，GB50243-2016 第 4.2.5 条要求非金属风管和复合材料风管的耐火极限必须满足设计要求；同规范第 6.2.2 条要求防火风管的本体、框架与固定材料必须为不燃材料。我们厂防火板用的双彩板就是冲着这条强条来的——8mm 起步，做单时料厚标"双彩/8"。

## 延伸：做单这关，为什么总被低估

干这行十多年，我越来越觉得：**风管厂最容易出错的地方，不在车间，在录单那十分钟**。镀锌板做错了还能焊，防火板切错了就是废料，一张板几十块，一错错一摞。

同行小厂我也见过不少，防火板单子大部分靠"老规矩"三个字撑着——老师傅心里有数，新来的全靠猜。这种模式，老师傅一退休就断层。我们厂把做单规则写成手册、录进系统，就是不想让"规矩"只活在老师傅脑子里。

防火板这块市场在涨，消防排烟的项目越来越多。谁先把做单规范化，谁就先吃下这块蛋糕。未来防火板项目只会更标准化，指望"口口相传"是走不远的。

## 实操上注意这几条

| 场景 | 记牢 |
|------|------|
| 客户没写长度 | 默认标准直管 1200，跟客户确认 |
| 客户说"直管堵" | 是直管带堵头，不是单独堵头 |
| 长度 600 / 1200 | 商榷减为 590 / 1190，省料不拼板 |
| 长度 > 2000 | 必须拆「标准节 + 短节」 |
| 口径周长 > 2400 | 别做口字形，按表换 U+I / L / 四片 |
| 算量 | (宽+高)×2×长，半成品按实际开料算 |
| 缩尺 | 2025 年 9 月起侧板缩尺、母口负尺，别按老习惯 |

## 结尾

防火板直管这活儿，看着简单，做单的门道一点都不少。小周现在下单前会主动问一句"长度多少"，师傅也不愣神了。就这一个小改动，车间少返工好几节管子。

下回客户再跟你说"老规矩"，先问清楚——你问的这一句，值不少钱。
