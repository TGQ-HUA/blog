## 引子

上个月车间老张拿了块法兰料来找我。

"唐哥，你看看这个孔——边距75mm，但到中间变成130多，两头稀中间密，装上去看着就不对劲。"

我一看就知道了。这是旧规则"固定首孔"打出来的——首孔固定110mm边距，中间再均分剩下的。边长800mm还行，要是碰到650mm、950mm这种不上不下的尺寸，孔距就特别难看。

老张说甲方那边拍照了，说"法兰孔距都不均匀，这风管质量能好？"

我无言以对。甲方不一定懂技术，但眼睛不瞎。

## 新旧规则到底差在哪

2026年1月6号之前，我们厂一直用的"固定首孔"规则。之后换成了"整边均分"。

表面上看就是算法改了改，但车间师傅和现场安装的感受完全不一样。

### 旧规则：固定首孔

核心就一条：**两端首孔固定边距110mm，中间再均分。**

拿800mm边长，要求孔距≤140mm来算：

```
中间区域 = 800 - 110×2 = 580mm
段数 = Ceil(580/140) = 5段 → 从左到右共6个孔（含两端首孔）
实际中间孔距 = 580/5 = 116mm
```

两端孔距110mm，中间116mm，看着还行。但换一个尺寸试试。

650mm边长：

```
中间区域 = 650 - 220 = 430mm
段数 = Ceil(430/140) = 4段 → 5个孔
实际中间孔距 = 430/4 = 107.5mm
```

两端110mm，中间107.5mm，差了2.5mm。孔一多，视觉上就是"两边松中间紧"。

更离谱的是小边——边长<220mm直接不打孔，但很多小边其实可以打一个孔固定。旧规则一刀切了。

### 新规则：整边均分

核心也一条：**整条边等分，孔距均匀。**

还是800mm，要求≤140mm：

```
段数 = Ceil(800/140) = 6段 → 5个孔
实际孔距 = 800/6 = 133.33mm ✓
```

650mm：

```
段数 = Ceil(650/140) = 5段 → 4个孔
实际孔距 = 650/5 = 130mm ✓
```

每个孔之间距离一模一样。甲方拿尺子量任何一个孔距，都一样。说不出闲话。

有同行问我新旧规则到底差在哪，一张表说清楚。

| 对比项 | 固定首孔（旧） | 整边均分（新） |
|--------|:-----------:|:-----------:|
| 首孔边距 | 固定110mm | 自适应 |
| 孔数算法 | 中间区域均分 | 整边均分 |
| 小边不打阈值 | < 220mm | < 150mm |
| 孔距均匀性 | 两端和中间不一样 | 全部均匀 ✅ |
| 计算复杂度 | 两步计算 | 一步到位 |
| 适用建议 | 历史未完结项目 | 新项目默认 |

## 改规则之后的变化

换了新规则之后，有两个明显的好处。

**一是车间师傅不用记两个数了。** 旧规则首孔110mm、小边220mm，师傅得背两个阈值。新规则一句话讲完："整条边均分，小于150mm不打孔。"新来的学徒教一次就会。

**二是返工少了。** 以前因为孔距不均匀被甲方退货的情况，半年碰过三四次。换新规则之后，一次都没有。

但有个例外要注意——**当孔距<100mm时，还是用固定首孔规则**。因为边长太短，整边均分算出来的孔距可能比要求的还大，这时候固定首孔更稳。首孔边距取75mm。

## 这个事背后的道理

打孔规则这件事，在整个风管制造里算是很小的一个环节。但越是这种小环节，越能看出一个厂的"底子"。

我见过不少厂，打孔规则十年没变过。不是不想改，是没人想过要改——"以前就是这么干的""甲方也没说不行"。直到有一天有人拍了照、说了话，才意识到老规则确实有毛病。

**风管这行，规矩是干出来的，但规矩也不是不能改。**

改一个孔距算法，成本为零。改完之后车间顺眼了、甲方没话说了、返工也少了。这种改动不做，不是技术问题，是意识问题。
