上周新来的小林做单，客户微信发过来一句“90°弯头，500×200，R200，2节”。她照着填报价单，规格栏写 500x200，写完给我看。

我看了两秒，问她：这句是左右转还是上下转？

她愣了一下，说这两句不是一样的吗。

不一样。照着错的那个做，件拉回来正好差 90 度。

## 客户的口语，和报价单上的字段，中间隔着一层翻译

客户嘴里的“90 度弯头”，只说了一半的信息。做单的人要把这句话落成报价单上的字段：规格、R、数量、接口、厚度、状态，一格一格填。

风管拐弯有两种拐法。在水平面上左右拐，叫水平弯；在竖直面上上下拐，叫立弯。客户习惯只写“宽×高”，可这两种拐法写出来看着差不多，靠的是口径顺序来分辨：

- 水平弯：宽 500×高 200，规格落 500x200
- 立弯：高 200×宽 500，规格还是 500x200，但客户那句里是“高”写在前面

按我们做单的老规矩，客户表述里宽在前是水平弯，高在前是立弯。所以往报价单上写 500x200 之前，得回头看一眼客户那句话里的顺序。

S 弯是同一个道理。偏差 S 弯（左右偏）按宽×高写，高差 S 弯（上下偏）按高×宽写，也是翻转口径。这一条新人最不容易反应过来，因为两个件的规格栏填的数字一模一样。

## 多口的件，口序本身就是信息

三通四通更直白，客户报口的顺序就是装配的顺序：

| 件 | 客户口述 | 报价单上对应的口 |
|------|------|------|
| 侧三通 | 500×200-250×200-320×200 | 底口 / 顶口 / 侧口 |
| 正三通 | 500×200-250×200-320×200 | 底口 / 左口 / 右口 |
| 四通 | 500×200-400×200-320×200-250×200 | 底口 / 顶口 / 左口 / 右口 |

三通上三个口尺寸常常都不一样，顺序一换，等于让车间照着错的做。这种件我们做单时要调图出来核一遍，看支口在哪个面、往哪偏、偏多少。客户一句话里装不下这些，硬填就是猜。

## 客户没写的那部分，才最容易出事

客户不会每次都写全。做单时按这几条默认值补：

- 弯头不写角度，按 90°；不写 R，按 R200
- 直管不写长度，按标准节长度走：共板接口 1160，角铁 1235，插条 1220，直边 1250
- 短直管必须给长度，客户没给就按短节就料长度走
- 大小头不带偏差说明，按对中；带偏差的必须参图
- 三通四通对口默认对中，有高差默认底平
- 变径做弧还是做菱角：偏差 ≤100 做内弧，大于 100 做内菱角

这些默认值省事，代价也摆在那儿：客户写含糊的时候，判断依据只能是“常规”。碰上不常规的活，默认值正好就是错的那一个。

## 行业里没有“表述标准”这一说

国标管的是成品。GB50243-2016 管风管做出来合不合格、验不验得过，管不到客户下单时怎么写。所以各厂的口语五花八门，同一个弯头，五个客户五种写法，做单的人就得天天干这层翻译。

客户的话不会变。能变的是我们自己这一层：把口语到字段的对应关系固定成一张表，新人来了照表填，比口口相传稳。

## 实操上注意这几条

| 客户说 | 报价单上要落的字段 |
|------|------|
| 直管：1000×500—5节 | 规格 1000x500、数量 5、长度按标准节 |
| 短直管：1000×500×400—3节 | 规格、长度 400、数量 3 |
| 弯头：宽500×高200—R200—2节 | 水平弯；规格 500x200、R200、数量 2 |
| 弯头：高200×宽500—R200—2节 | 立弯；口径翻转 |
| 偏差S弯：宽500×高200—长700—偏300 | 规格 200x500、长 700、偏 300 |
| 高差S弯：高200×宽500—长700—偏300 | 口径翻转 |
| 大小头：上宽800上高400—变下宽500下高320—长500 | 规格(1) 800x400、规格(2) 500x320、长度 500 |
| 侧三通：500×200-250×200-320×200—长720—R200 | 底口/顶口/侧口，长 720、R200 |
| 四通：500×200-400×200-320×200-250×200 | 底口/顶口/左口/右口 |

报价单上的列是固定那几栏：编号、材质、名称、规格、长度或 R、数量、厚度、接口、状态、备注。状态栏只有一个字，半或者全，说的是这件活按半成品走还是按成品走，填错了车间就多一道焊或者漏一道。

小林现在改了个习惯：客户那句话先抄在纸上，再一个字段一个字段往报价单里填。抄一遍比读一遍管用，尤其是口径顺序这种，看着没问题的地方最容易反。她那句“这两句不是一样的吗”，我们技术部好几个人刚来的时候都问过。
