上星期车间接了张双层保温管的单，带班师傅拿着图纸来找我：外壁是不是比内胆大一圈，把内胆套进去就行？我说正好反过来——长度上内胆比外壁长 200 多毫米，外壁是短的。

师傅懵了。这不怪他，双层保温管这活，好多厂都不爱接，一是夹层棉的活琐碎，二是内胆外壁两套尺寸，差一点现场就接不上。我们厂也是吃亏吃出来的，现在把规矩钉死在表里。

## 先搞懂三层结构

双层保温管就三样东西：内胆（内层金属管）、外壁（外层金属管）、中间夹层填保温棉，四周要支撑。

关键就在这：**内胆和外壁是分开下料、分开做的，不是"套进去"的关系**。内胆负责走风和连接，外壁负责包住保温棉。所以两套尺寸完全不能按"外壁=内胆+板厚"来算。

## 核心一条：外壁比实长短 200

我们厂规矩里最常用的一条：

- **外壁长 = 实长 - 200**
- **内胆长 = 外壁长 + 200 + 20**，也就是比外壁长 220

为什么？内胆两端要伸出来做连接（法兰、翻边、对焊），外壁是包棉的壳，短一截，两头留出内胆的接口位。这 200 就是给连接和棉让出来的位置。

弯头、S弯、大小头、三通，凡是带长度的，都走这个逻辑：外壁实长减 200。三通支咀也一样，外壁支咀最短做 50，内胆支咀 = 外壁支咀 + 100 + 夹层 50。

## 还有个 20.7 的勾股偏差

直位和支咀的换算里有个"勾股偏差"，约 **20.7mm**（夹层 50 时）。

啥意思？内胆和外壁的半径不一样，斜着的那段（弯头、斜三通）两边差出来的斜边长就不一样，这个差值得补回去。比如矩形弯头：

- 外壁直位 50（硬性要求）
- 内胆直位 = 50 + 100 + 20.7 = 170.7

你说 20.7 毫米能干嘛？就是这 20 来毫米，不补上，弯头装到一半棉就鼓出来，外壁合不拢。干这行的都懂，几毫米的账，最后都算在返工上。

## 一表对照：保温层 50 的常见管件

有同行问我要过这张表，直接抄：

| 管件（夹层 50） | 外壁 | 内胆 |
|------|------|------|
| 直管（圆形 1230） | 开料 1000（1 米宽钢卷） | 开料 1250（常规钢卷） |
| 直管（圆形 1450） | 开料 1250 | 1250 + 短节（200+40）激光下料 |
| 90° 圆弯头 R300 | 直位 50，R100，5 段 | 直位 150+10，R150，5 段 |
| 45° 圆弯头 R350 | 直位 50，R150，3 段 | 直位 150+10，R200，3 段 |
| 90° 矩形弯头（内菱外弧） | 直位 50，R100，3 段 | 直位 170.7，R129.3，3 段 |
| 圆 S 弯 长1100 偏570 | 长 900，直位 80 | 长 1100+20，直位 234.5+10 |
| 圆大小头 长700 | 长 500，两头直位各 50 | 长 700+20，大头直位 143.8+10，小头 156.2+10 |
| 圆侧三通 T 型 长800 | 长 600，支咀 50 | 长 800+20，支咀 200 |

两处硬性要求记死：**外壁直位不低于 50**，**内胆直位 150+10**。外壁直位短了，棉压不住；内胆直位短了，连接没处下手。

## 矩形弯头默认内菱外弧

矩形弯头我们默认做内菱外弧，不做内外都圆。一来好下料，二来棉好塞。保温棉的活还有个讲究，外壁对接用方接头围板：尺寸 = 外壁口径 +3，长 240mm，两头直边，大边折 15。

别小看那个 +3。外壁围板不做大这 3 毫米，套上去紧巴巴，师傅得拿锤子敲半天。

## 保温棉本身有国标管着

夹层棉这块，GB50243-2016 第 10 章有硬性要求，我们厂对着改过：

- **10.2.1 绝热材料**：吊顶内风管保温须 B1 级（难燃）及以上，防排烟系统须 A 级（不燃）
- **10.2.2 保温层厚度**：室内空调风管 25~40mm（玻璃棉）；室外 40~60mm 还要加外护层
- **10.3 保温钉**：钉长 ≥ 保温层厚度 + 10mm；风管底面 ≥16 个/m²、侧面 ≥12 个/m²、顶面 ≥8 个/m²
- **10.4 毡材包裹法**：搭接 ≥ 50mm，无空鼓

我们夹层做 50，就是按室外空调风管这个区间取的。棉的密度、厚度不对，验收时 10.2.2 这一条就过不去。

## 延伸两句

双层保温管这活，说穿了就是"两套尺寸 + 一层棉"，但多数厂不爱接，嫌烦。图纸上只标一个实长，内胆外壁各是多少，全靠排版的人心里有数。师傅干得顺不顺，往往就取决于这张换算表有没有钉在墙上。

这行就是这样，看着是手艺活，底下全是账。哪家先把账算明白了，哪家返工就少。

## 实操上注意这几条

1. 外壁长先算：实长 - 200，所有带长度的管件通用
2. 内胆比外壁长 220（200 + 20 搭接位），弯头直位、支咀另加勾股偏差 20.7
3. 外壁直位不低于 50，内胆直位 150+10，两头硬性
4. 矩形弯头默认内菱外弧，外壁对接围板 = 口径 +3、长 240
5. 夹层 50 按 GB50243-2016 室外空调风管 40~60mm 区间取，棉的等级按 10.2.1 对号入座

那张表我贴在排版室了。师傅现在下双层管的料，先找表再动刀，再没出过"外壁长了塞不进棉"的事。
