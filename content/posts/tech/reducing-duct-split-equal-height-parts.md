## 老张把图往我桌上一放，说车间不愿意接这个活

上个月跟单的老张拿了张图过来，一根变径三通：主口 500×400，两个支口都是 500×200。客户催得急，车间看了一眼说这活得往后排。

我问师傅卡在哪。他说主口这边 400 高，支口那边 200 高，四条边四条长度，展开图是斜的，咬口往哪儿放都得现算。这种件做一件两三个小时，废一张板半天就白干了。

我们把这张图重新拆了一遍，拆成三个标准的件。下午车间的活就出来了。

## 照图硬做，问题都堆在展开那一步

客户图纸画的是气流最后要走到哪，车间要的是这个件展开以后多长、咬口在哪条边。中间这一步翻译，落到我们身上就是展开图。

不等高的件，主口和支口的四条边长度各不相同，展开图是个斜梯形叠斜梯形。做成一体件，只能走 4 片式，还得把不等长的边对齐拼接。老做法是靠师傅的经验顶着，谁手艺好谁能做，手艺一般的就得返工。也有图省事的，把支口斜着接过去，中段截面收缩，风量跟着小一截，这账最后还是要算在风阻上。

我们现在的做法不跟展开图较劲，先在单子上就把形状改掉。

## 加大小头改等高，规则就四条

1. 主口高度定下来，所有支口改到这个高度，件就成了等高件，四条边左右对称，展开图规规矩矩。
2. 每个高度不一样的支口，各加一个大小头补回去。
3. 大小头默认长度按 300mm。
4. 大小头一端是主口高度，另一端是支口原来的高度。

老张那张图拆完是这样：三通做成 500×400，两个支口都改到 400 高；两个支口各挂一个 500×400 变成 500×200 的大小头。原来一个件，现在三个件。

四通、弯头是一个道理。变径四通主口 500×400，支口分别是 500×200、500×200、400×300，改完是支口 1、支口 2 走 500×400 加大小头，支口 3 因为宽度只有 400，走 400×400 加一个 400×400 变 400×300 的大小头。变径弯头同理，主口 500×400、支口 500×200，就是弯头 500×400 加一个大小头。

## 那 300 这个长度是怎么来的

有同行问过我，加的大小头长度凭什么定 300。这个数不是拍出来的，是按收缩角倒推的一个起步值。

JGJ141-2017 第 6 章 6.2.2 对变径角度有明确要求：扩散（小变大）推荐不超过 15°，最大不超过 30°；收缩（大变小）推荐不超过 30°，最大不超过 60°。双面偏变径的长度按这个公式算：

```
L = (B − b) / (2 × tan(θ/2))
```

B 是大端尺寸，b 是小端尺寸，θ 是收缩角。我们按这个公式把常用尺寸核了一遍（双面偏，两边对称收）：

| 两端差 (B−b) | 做到 15° 需要长度 | 做到 30° 需要长度 | 做到 60°（上限） |
|------------|------------------|------------------|------------------|
| 100mm | 380mm | 187mm | 87mm |
| 200mm | 760mm | 373mm | 173mm |
| 300mm | 1139mm | 560mm | 260mm |
| 400mm | 1519mm | 746mm | 346mm |

反过来看 300 这个默认值：两端差 100mm 的时候，300 长长对应的角度是 18.9°，过得去；两端差 200mm 就是 36.9°，已经超过推荐的 30°，好在没碰到 60° 的上限；两端差到 300mm，就跑到 53.1°，快贴上上限了。

这里还有个细节。我们厂做的大小头多数是一边平的（宽不变或者高不变那种），一边平的时候斜面全落在一面，同样的长度看着更陡。400 收到 200、长 300，一边平的单面角度是 33.7°，双面对称是 36.9°，量级差不多，都过了推荐的 30° 线。所以定长度的时候我们照这张双面偏的表往上取整，一边平的也不会吃亏。想回到 30° 以内，400 收到 200 这种长度得做到 380 往上，我们一般取个整数 400。现场位置紧、加不长的，就在图纸上说明，让设计那边知道这地方会多出一点阻力。

## 大小头本身也有成型门槛

拆件的时候得顺手把形式定了，不然排版的师傅还得回头问一遍。

半周长小于 2000mm、长度小于 1000mm，而且是单边平（底平或顶平的时候宽度不变，边平或侧平的时候高度不变），这种走 U+I 形；尺寸超了，或者两头都在变（宽度高度同时变），一律 4 片式。

这条界限不复杂，难的是它是跟着拆件一起判的。我们把它写进单子的备注里，做单的人一次定完，车间拿到手不用再猜。

## 超长的 S 弯，拆法一样

偏移量大、长度又长的 S 弯，做成一体件展开以后中段会收得很猛。这事在我们厂是有教训的，S 弯做成偏瘦的形状，装上去工人拉直了凑合，中段截面一小，风量就下来了。

长 S 弯按两节或三节拆。举两个实际拆过的：

| 原始 S 弯 | 拆出来的件 |
|-----------|-----------|
| 宽 400、长 850、偏移 300、左右直位 50 | 弯头 2 节（内 R300，左直位 50，右直位 114.6） |
| 宽 1000、长 1700、偏移 200、左右直位 100 | 弯头 2 节（内 R300，左直位 100，右直位 62.3）+ 标准直管 1 节，长 1160 |

拆成两节弯头中间直管连，比做一个大 S 弯好排好折，装的时候也好对，中段的截面能保住。

## 有同行问我，这么拆，录单怎么录

一拆三，单子上的件数就上去了，别人看单子容易懵。我们的做法是把拆出来的件按顺序编在一张单上，谁配谁写清楚：

| 客户报的件 | 客户口径 | 拆出来的件 | 数量 |
|-----------|---------|-----------|------|
| 变径三通 | 主口 500×400，支口 500×200 ×2 | 三通 500×400（支口等高） | 1 |
| | | 大小头 500×400 → 500×200，长 300 | 2 |
| 变径四通 | 支口 500×200、500×200、400×300 | 四通 500×400（支口等高） | 1 |
| | | 大小头 500×400 → 500×200 | 2 |
| | | 大小头 400×400 → 400×300 | 1 |
| 变径弯头 | 主口 500×400，支口 500×200 | 弯头 500×400（支口等高） | 1 |
| | | 大小头 500×400 → 500×200 | 1 |
| 长 S 弯 | 宽 1000、长 1700、偏移 200 | 弯头（内 R300，左直位 100、右直位 62.3） | 2 |
| | | 标准直管 1160 | 1 |

## 拆也是有代价的

多一个大小头，就多一对接口，漏风点和工时都跟着涨。差得不多、现场又实在挤不开的活，硬做一体件我们也做过，做得出来。这套拆法是给大多数活用的，不是拿来卡人的。

早些年这类活照图硬做，能顺顺当当做的师傅就那么两三个。现在我们把判断放进流程：拿到变径件先看主口高度和支口差多少，差得多就拆，拆完把形式顺手定掉。做单的人不用是老师傅，看一眼就知道该拆几件。

老张现在拿到变径的件，先翻一页看两端差，心里就有数了。有同行问过我拆不拆的判断标准，我的建议就一条：两端差在 100mm 以内、现场又挤的，照图做一体件也行；差得多的，拆。拿不准就把主口支口的尺寸发过来，我帮你把那个角度算一下。
