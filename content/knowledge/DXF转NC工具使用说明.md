**产品：**DXF转NC工具　|　**作者：**奇美星　|　**当前版本：**V2.3.7

DXF转NC工具是风管厂技术部内部用的**开槽机前处理工具**——把排版出的 DXF 直接翻成机床能跑的 NC 切割程序。图纸按图层分好工艺，每个图层一套刀号/切深/进给/转速；文件拖进去、点一下，出来的 `.NC` 就能上机。

---

## 一、软件简介

### 它解决什么问题

排版软件出的 DXF 是"图"，机床要的是"程序"。中间这段换算，手工做又慢又容易错：

- 每件的轮廓要按刀径**让刀**（内偏/外偏），孔要往孔内偏、外形往外形外偏
- 一件活上既有外形又有孔、还有孔里的岛，**先切哪个后切哪个**直接决定工件会不会移位切废
- 每个图层的刀号、切深、走刀/下刀进给、转速、抬刀高度都不一样，一次要改十几处
- 入刀点打在哪里、从哪个角下刀、走刀是顺时针还是逆时针，师傅有讲究
- 凹角要补刀（V 口）、大件要留横切缝（槽线），这些都得在图上先画出来

这个工具把上面这些一次做完：**读 DXF → 按图层套工艺参数 → 按规则偏移/排序/补槽 → 输出 NC**，并且能在屏幕上把刀路按切割顺序走一遍给你看。

### 主要能力

| 能力 | 说明 |
|------|------|
| **批量生成** | 一次拖入多个 DXF（或整个文件夹），按件逐个出 NC |
| **图层化工艺** | 每个图层（刀路类型）一套刀号/切深/走刀F/下刀F/转速/抬刀Z，存在 ini 里，改一次长期有效 |
| **自动识别内外形** | 外形外偏、孔（内形）内偏；内形里套的岛单独成件，**由内到外**切割 |
| **自动摆正** | 拖入的图自动平移：最左点贴原点偏移 X、最下点贴原点偏移 Y，不用在 CAD 里对刀 |
| **走刀排序** | 按件、按环、按上下顺序排好切割次序，支持手动调序 |
| **入刀点可设** | 起点角（左上/左下/右上/右下）+ 贴底件单独设角 |
| **凹角补槽** | 凹角自动补 V 口刀路（补槽角度阈值可调，0 = 关闭） |
| **槽线成组** | 按数量一次插入横切缝（第 1 组切"数量+1"条，第 2 组起切"数量"条，改一条全链重算） |
| **方块排版** | 在件外插工艺方块（宽×长×数量），程序按板料最大尺寸校验放得下放不下 |
| **补料排版** | 选中件 Ctrl 多选 → 右键补料，自动排出一张补料图（多种方案取用料最短）|
| **走刀预览 / 演示** | 屏幕上按"段-块"顺序把刀路走一遍，入刀点、走线方向、切割次序一目了然 |
| **两套弧码方案** | 配套 CAM / 配套精雕，弧形件的指令格式一键切换（见第八节）|

### 输入输出

| 项目 | 说明 |
|------|------|
| **输入** | DXF（CAD 另存的 ANSI 版或 UTF-8 版都能读；多段线 LWPOLYLINE、圆弧、圆、直线均支持）|
| **输出** | `.NC` 切割程序，默认与 DXF 同名同目录 |
| **补料图** | 排版补料时另出一张 DXF（标准 R12 结构，CAD/下游软件可直接打开）|
| **坐标精度** | 3 位小数（圆弧件的圆心误差控制在 0.001mm 级，设备不会判"终点不在圆弧"）|

## 二、安装与设备绑定

### 安装

1. 双击安装包，按向导完成安装（默认装到 `C:\Program Files\DXF转NC工具`）
2. 桌面与开始菜单会生成快捷方式
3. **安装向导最后一页默认勾选「查看使用说明（网页版）」**，点"完成"会打开本页；不想看可直接取消勾选

> ⚠️ 安装目录必须可写——程序运行时要写工艺参数与绑定记录。安装程序已自动为该目录授权。
> 升级安装**不会覆盖**你改过的参数（ini 只在首次安装时落盘）。

### 程序目录里的文件

| 文件 | 说明 |
|------|------|
| `DXF转NC工具.exe` | 主程序 |
| `DXF转NC工具.ini` | 全部工艺参数（程序同目录同名 ini，ANSI 编码，可用记事本直接看/改）|
| `security.ini` | 设备绑定记录（首次绑定成功后生成）|
| `密码图标.bmp` | 绑定界面用图（缺失会导致程序启动崩，勿删）|
| `CyanNight.vsf` | 深色主题样式文件 |

### 设备绑定（首次使用）

软件与电脑一对一绑定，每台机子一套：

1. 首次启动会弹出「**首次使用 - 绑定设备**」窗口，界面上显示本机**硬件标识**（由 CPU、主板、硬盘信息生成，每台机子唯一）
2. 把这串**硬件标识**报给技术部，取回对应的**固定密码**与**绑定密钥**
3. 两项分别填入窗口 → 点确定 → 绑定完成

之后再启动自动通过，无需重复输入。**换电脑、或更换主板/硬盘**后会提示「**设备变更验证**」，需要重新报硬件标识、重新绑定。

> 提示：绑定记录写在程序目录的 `security.ini`，卸载重装不清除绑定；只有硬件真的变了才需要重新验证。

## 三、界面总览

主窗口分四块：**顶栏（参数与操作）→ 左侧文件列表 → 右侧预览 → 底部日志**。

### 顶栏

| 控件 | 用途 |
|------|------|
| **输出目录** + 浏览 | NC 存哪里。**留空 = 存到 DXF 同目录**（同名 `.NC`）|
| **添加文件…** | 选择要处理的 DXF（可多选）|
| **添加文件夹…** | 整个文件夹加入（含子目录里的 DXF）|
| **移除选中** / **清空列表** | 从列表里拿掉条目 |
| **工艺设置…** | 打开图层工艺表（见第五节）|
| **参数设置** | 打开全局参数窗（见第五节）|
| **添加空白板** | 不用 DXF，直接新建一块板料条目，用方块/槽线排版 |
| **开始生成 NC** | 按列表逐件生成 |
| **☑ 不含M91、M92** | 勾上后输出的 NC 里不带 M91/M92 指令 |
| **弧码方案** | 下拉切换「配套CAM / 配套精雕」，切换后自动记住 |

### 文件列表

- 直接**把 DXF 文件或文件夹拖进窗口**也能加入（拖入即自动解析并出 NC）
- 每行两列：**文件** / **状态**（待处理 / 已生成 / 出错原因）
- **点选某行** → 右侧预览切到该件
- **右键**：重命名（改条目名，NC 文件名与程序号跟着改，改完自动重新生成）/ 另存为…（把已生成的 NC 复制到你指定位置）

### 预览区

- 标题栏说明图例：**序号 = 段-块（环切顺序）、绿点 = 入刀、绿箭头 = 走线方向**
- 鼠标**滚轮缩放**、**按住拖动**平移；**双击 = 暂停/继续**走刀演示
- **把 `.nc` 文件拖进窗口**：不进列表，直接弹出「NC 码查看」窗看代码（只读，可全选复制）

### 信息面板（预览右侧）

| 控件 | 用途 |
|------|------|
| **虚线框 = 用量四边(主件)** | 示意这件活的用量范围（虚线框）|
| 宽(横) / 长(纵) / 放置 | 插方块时的尺寸与放置位置（右下侧列(方块) / 顶部槽线列(横缝)）|
| **板料最大尺寸(通用)** | 宽 / 长（默认 1250 × 2500），插方块/槽线时做越界校验 |
| **插入方块** / **删除** / **修改尺寸** | 方块列表的增删改（方块 = 件外工艺块）|
| 方块列表 | 当前件已排的方块 |

### 料块面板

| 控件 | 用途 |
|------|------|
| **入刀角（仅外形）** | 单独调整选中件的入刀角（左上/左下/右上/右下）|
| **上移 / 下移** | 手动调整料块的切割先后顺序（调完重新生成）|
| **初始化** | 恢复程序自动排序 |
| 料块列表 | 每行一个料块（块号 + 类型）|

### 演示条

速度（慢/中/快）、后退一步、后退播放、播放/暂停、前进一步、初始化——用来回看刀路是怎么走的。

## 四、操作流程

1. **加文件**：拖入 DXF（或文件夹），或点「添加文件…」——程序自动解析并摆正
2. **看预览**：点选文件行，确认图形、用量、料块是否对
3. **（可选）调参数**：「参数设置」改全局工艺；「工艺设置…」改图层刀号/进给
4. **（可选）排版**：需要插方块 / 插槽线 / 补料的，在右侧信息面板做（见第六节）
5. **点「开始生成 NC」**：进度窗走完后看状态列
6. **取结果**：按输出目录取 `.NC`（留空时就在 DXF 旁边）
7. **（可选）看走刀演示**：切到该件，用演示条按段走一遍

> 空白板（不用 DXF 的排版件）走同一套流程：加空白板 → 插方块/槽线 → 生成。

## 五、参数说明

### 参数设置（顶栏「参数设置」）

| 参数 | 默认 | 说明 |
|------|------|------|
| **槽线 x 起点** | -50 | 横切缝的左端 x 坐标（一般取板外一点，保证切透）|
| **槽线 x 终点** | 1280 | 横切缝的右端 x 坐标 |
| **V口补槽角（≥不补，0=关）** | 90 | 凹角补槽的**角度阈值**：行进转角 ≥ 该值才补；填 0 = 全部不补 |
| **原点偏移 X / Y** | 8.5 / 8.5 | 摆正基准：图的最左/最下贴到这两个值上（对应机床原点外的余量）|
| **刀径** | 7.5 | 让刀量 = 刀径 ÷ 2（即每侧 3.75）|
| **面积闸值 m2** | 0.5 | 环序用"闸值模式"时的**小件判定**面积（小于它的件按小件排）|
| **起点角** | 左上 | 每件的入刀角：左上 / 左下 / 右上 / 右下 |
| **底部起点角** | 右下 | **贴底的环单独用这个角**入刀（不单独设时跟随起点角）|
| **方向** | 逆时针 | 环绕行方向：逆时针 / 顺时针 |
| **环序** | 面积闸值-上到下 | 环的切割排序：**面积闸值-上到下** / **面积闸值-下到上** |

手改 ini 也可以（`DXF转NC工具.ini` 的 `[全局]` 段），改完重开程序生效。

### 工艺设置（顶栏「工艺设置…」）

一张表，一行一个图层：

| 列 | 含义 |
|----|------|
| **图层名** | DXF 里的图层名（要与图纸一致；`(默认)` 行用于没单独配置的图层兜底）|
| **刀号** | T 指令刀号 |
| **切深** | Z 切深 |
| **走刀F** | 走刀进给（G1 F）|
| **下刀F** | 下刀进给 |
| **转速** | 主轴转速（S）|
| **抬刀Z** | 抬刀高度 |

- 用**新增行 / 删除行 / 上移 / 下移**维护；**行序 = NC 里的输出段序**，想让哪一层先切就往上排
- 表里没有的图层：生成前会弹窗提示，可选「用(默认)参数处理 / 跳过这些图层 / 取消」

### 顶栏开关

**☑ 不含M91、M92**：勾上后输出的 NC 不含 M91/M92 指令（用于不需要该动作的机型）。

## 六、排版与补料

### 插入方块（件外工艺块）

1. 在信息面板填 **宽(横) / 长(纵) / 数量**，选 **放置**（右下侧列(方块) / 顶部槽线列(横缝)）
2. 点 **插入方块** → 方块进方块列表，预览里出现虚线框
3. 选中方块可 **修改尺寸** 或 **删除**
4. 板料最大尺寸（宽/长）用来校验排得下——超了会提示

### 插入槽线（横切缝，成组）

- 点 **插入槽线**，填 **数量**：程序按"**第 1 组切 数量+1 条、第 2 组起切 数量 条**"成组插入
- 槽线位置从用量顶往上排，x 范围取「参数设置」里的槽线 x 起点/终点
- **改一条，整条链自动重算**——不用手工一条条对

### 补料（选中件排新图）

1. 在**料块列表**里按住 **Ctrl 多选**要补的件
2. **右键 → 补料(选中件排版出新图)**
3. 程序自动排版（行式 × 3 种 + 最大矩形 × 2 种，**取用长最短的方案**），件与件留一个刀径净距
4. 件上原有的槽线会跟着件一起补，**图层不变**
5. 结果作为新条目出现在列表里，可直接生成

### 空白板

不用 DXF 也能干活：点 **添加空白板** → 条目自动带上时间戳（如 `空白板_20260924_153012`）→ 用「插入方块 / 插入槽线」排好后生成。空白板只排槽线也能生成。

## 七、走刀预览与演示

- **预览图**：静态显示图形 + 切割顺序号 + 入刀点（绿点）+ 走线方向（绿箭头）
- **演示条**：点「播放」按段-块顺序走刀；速度可选慢/中/快；也可「前进一步 / 后退一步」逐段看
- **看 NC 代码**：把 `.nc` 文件拖进窗口即弹出「NC 码查看」窗（只读文本，可复制）

> 预览是"看到的"，NC 是"机床跑的"，两者用同一份几何数据，**弧的走向两边一致**（V2.3.6 起）。

## 八、两套弧码方案（配套 CAM / 配套精雕）

弧形件（圆孔、圆角、扇形弧）的指令格式，CAM 与精雕两台/两套软件要求不一样，顶栏下拉一键切换，切换后自动记住。

| 项目 | **配套 CAM** | **配套精雕** |
|------|--------------|--------------|
| 弧指令 | `G2` | `G02` / `G03`（按走向）|
| I / J 含义 | 圆心**绝对坐标** | 圆心**相对起点的增量** |
| K | 无 | `K0` |
| 直角顶点 | 直接走 | **每个凸角加圆角**，半径 = 刀径 ÷ 2 |
| G17 平面选择 | 不需要 | **首条弧前输出一行 G17** |
| 其他 | N 号、坐标 3 位小数、Z35 | 同 |

> 选错方案的典型症状：精雕机报「第 1 路径使用 G02/G03 时终点座标不在圆弧」→ 检查是不是选了 CAM 方案。
> 圆角只加在**凸角**，凹角不加；圆角方向与环的走向一致。

## 九、常见问题

**Q：生成的 NC 上机报「终点座标不在圆弧」？**
A：① 确认顶栏「弧码方案」选的是**配套精雕**（精雕机必须用精雕方案，程序会在首条弧前加 G17）；② 确认用的是 **V2.3.3 或更高版本**（G17 是 V2.3.3 加的）。如果还有问题，把 DXF 和 NC 一起发回技术部。

**Q：圆弧走出来了，但走的是反方向的另一段弧？**
A：这是 V2.3.5 之前的老问题（弧的走向没传到 NC），**升级到最新版**即可。另注意：V2.3.6 之前**预览图**会把弧一律按顺时针画，看着像走反了，实际 NC 是对的——两处 V2.3.6 都已修。

**Q：料件上移/下移之后，精雕码里的 G17 不见了？**
A：V2.3.4 已修（手动调序走的是另一套输出代码，当时没同步）。升级即可。

**Q：孔切到孔外面去了 / 切到材料上？**
A：孔（内形）应当**向孔内偏移**。如果出现反的，检查该孔所在的封闭图形是否被识别成"外形"（偶数为外形、奇数为内形——嵌套关系靠这个判）。可把图发回技术部核对。

**Q：生成时提示"缺图层"？**
A：图纸里有图层没在「工艺设置」里配置。三种选法：用 `(默认)` 行的参数处理 / 跳过这些图层 / 取消后先去补配置。

**Q：方块的摆放位置和想的不一样 / 排版超板？**
A：先在信息面板核对「板料最大尺寸(通用)」是不是当前板料的实际宽长（默认 1250×2500）。放置位置有"右下侧列(方块)"与"顶部槽线列(横缝)"两种，按件型选。

**Q：换电脑了，原来的绑定还能用吗？**
A：不能，软件与硬件绑定。在新电脑上启动，把新的**硬件标识**报给技术部，取回固定密码与绑定密钥重新绑定。

**Q：怎么确认自己装的是哪个版本？**
A：看程序**窗口标题栏**的版本号（如 `V2.3.7`），再对照本页第十节的更新记录。
