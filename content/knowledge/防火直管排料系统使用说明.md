**产品：**防火直管排料系统　|　**作者：**奇美星　|　**当前版本：**V1.7

防火直管排料系统是技术部自研的防火板拆分下料排版软件。它把订单信息按防火板规格换算成开料数据（规格 / 数量 / 备注），再结合库存板材进行切割方案排版，输出可直接下发车间的下料清单，帮助车间用最省料的方式切板。软件内置材料汇总与 NC 下料码生成，从算料、排版到出码一站式完成。

---

## 一、软件简介

完整工作流程：

1. **订单录入** —— 手工录入、Excel 模板导入或从排版软件剪切板直接粘贴
2. **开料统计** —— 按类型与内尺 / 外尺、单彩 / 双彩把订单换算成开料规格
3. **库存管理** —— 登记车间可用板材（料厚 / 尺寸 / 数量）
4. **排版下料** —— 依据库存板材计算最省料的切割组合
5. **材料汇总** —— 按料厚统计用料长度与使用率
6. **下料写码** —— 按切割机格式生成下料 NC 码
7. **导出清单** —— 生成综合清单 Excel（订单 / 开料 / 材料汇总 / 排版）

支持五种下料类型：**4片式 / L型 / 口字型 / U+I型 / U+I型-反**（与车间工艺对应）。

## 二、安装与启动

1. 双击安装包，按提示完成安装（默认安装到 `C:\Program Files\防火直管排料系统`）
2. 桌面与开始菜单生成快捷方式，双击即可启动
3. 首次启动需通过密码验证与硬件绑定（绑定当前电脑），通过后进入主界面
4. **安装向导最后一页已默认勾选「查看使用说明（在线）」**，安装完成会自动打开浏览器显示本页面；不勾选则不会打开
5. 程序运行数据保存在安装目录，无需额外配置数据库

> ⚠️ 安装目录必须具有写入权限——程序运行时会读写存档文件（窗体数据存档.ini、库存表.ini）。安装程序已自动为安装目录授予用户写权限。

> 💡 升级安装不会覆盖已有的存档文件，库存数据与参数设置都会保留。

## 三、界面总览

主窗口分三个页签，顶部是订单信息区域（集中放置全局工艺参数）：

| 区域 | 内容 | 说明 |
|------|------|------|
| 订单信息区域 | 项目名称、内尺/外尺、单彩/双彩、下料方式、排料限制、切刀直径、排版方案显示 | 全局参数，影响开料与排版计算 |
| 订单录入 | 订单记录表单、开料记录表、开料表按钮区 | 录入订单、查看开料结果、手动拆分调整 |
| 排版下料 | 库存表、排料表、材料汇总表、排版/导出按钮 | 管理库存、执行排版、查看材料汇总、导出清单 |
| 下料写码 | 写码参数、写码组合列表、NC 预览框 | 根据排料结果生成下料切割 NC 码 |

## 四、参数说明

| 参数 | 默认值 | 作用 | 注意事项 |
|------|--------|------|---------|
| 内尺 / 外尺 | 外尺 | 决定算料公式按内尺还是外尺计算 | 切换后开料记录表自动重新计算 |
| 单彩 / 双彩 | 单彩 | 决定扣减值（单彩 1/2，双彩 1.5/3） | 切换后开料记录表自动重新计算 |
| 下料方式 | 加长扣宽 | 决定长 / 宽哪一边作为主边（加宽扣长 = 长宽角色对调后套同一套公式） | 切换顶部下拉会同步全部订单行并自动重算 |
| 排料限制 | 3000 | 降级判断阈值 + 4片式超长拆分长度 | 建议填库存常用料长，影响排料质量 |
| 切刀直径 | 7.5 | 排版时每切一刀的损耗宽度（mm） | 切 n 块料损耗 (n-1)×切刀直径 |

下料写码页签另有独立参数：刀径(7.4)、切断深度(9)、开槽深度(4)、首刀偏移(3.7)、X 起点(-50)、X 终点(1280)、割首刀（默认勾选）；以及双刀参数：切断刀号(1)、开槽刀号(2)、转速(24000)、抬刀高(20)、下刀 F(3000)、走刀 F(12000)。

## 五、订单录入

订单表共 7 列：**编号 / 长度 / 宽度 / 数量 / 类型 / 料厚 / 下料方式**。三种录入方式：

**方式一：手工录入**

1. 填写 编号、长度、宽度、数量、类型、料厚，点「项目添加」写入订单表
2. 选错行可「项目修改」或「项目删除」
3. **双击任意一行**弹出「修改类型与下料方式」窗口：可改类型（五选一）、下料方式（二选一），还能填「拆分数量」把一条订单拆成两条（留空 = 不拆分；填写时须大于 0 且小于原数量）

**方式二：Excel 模板导入**

1. 点「订单导入」，选择车间下发的 Excel 订单模板（.xlsx / .xls）
2. 程序按表头列名定位：NO → 编号、规格(1) → 长度、规格(1) 后一列 → 宽度、数量 → 数量、厚度 → 料厚、备注 → 类型
3. 备注列只识别「L型 / 4片式 / 口字型 / U+I型」，识别不到的按 4片式 处理

**方式三：剪切板导入**

1. 在排版软件（CAMduct）里复制订单内容（含 JOBHEADER / ITEM 标记的文本）
2. 回到本程序点「剪切板导入」，自动解析项目名称、编号、料厚、数量、长宽与类型
3. 只导入直管与短直管，平板 / 大小头 / S弯 / 弯头等自动跳过；导入前会清空原有订单表

## 六、开料统计

开料统计把订单数据按防火板规格公式换算成开料记录表（料厚 / 规格 / 数量 / 备注），结果自动按 **料厚 → 规格** 排序。

**触发方式**

- 订单信息区域的参数（内尺外尺 / 单彩双彩 / 下料方式 / 排料限制）变化时，停顿 300ms 后自动重新统计
- 也可点开料表按钮区的「重新开料统计」手动触发（会先清空事件记录）

**超长降级规则**

当某类型算出的规格超过排料限制时，按 **口字型 → U+I型 → L型 → 4片式** 逐级降级重新计算（U+I型-反 超长时降为 L型）；只有 4片式 才做超长拆分（按排料限制长度循环切段）。降级与拆分都会弹窗提示，并写入事件记录框（带订单编号）。

**开料表按钮区工具**

| 按钮 | 功能 | 示例 |
|------|------|------|
| 拆分规范 | 按规格拆分为两段，数量不变 | 规格2000×14 → 1500×14 + 500×14 |
| 拆分数量 | 按数量拆分为两项，规格不变 | 规格2000×14 → 2000×4 + 2000×10 |
| 删除选择条目 | 删除选中的开料记录行 | 选中行后点击即删 |
| 重新开料统计 | 清空事件记录并重新算料 | 参数改乱后一键恢复 |

## 七、库存管理

1. 输入 料厚、长度、数量，点「库存添加」加入库存表
2. 点击库存表某行，数据自动载入输入框，修改后点「库存修改」覆盖该行
3. 选中行点「库存删除」删除
4. 添加 / 修改后自动按 **料厚 → 规格** 排序；若与已有行 料厚 + 规格 相同，弹窗确认后数量自动合并
5. 库存数据自动存档（关闭程序时保存、启动时载入），无需手动保存

> ⚠️ 库存是排版的唯一料源。某料厚没有可用板材时，排版会提示「库存不足」并中止。

## 八、排版下料

点「防火直管排版」，程序按库存板材尺寸对开料零件做切割组合排版，结果写入排料表（基材尺寸 / 数量 / 组合 / 使用率 / 余料长度），自动按 **料厚 → 基材尺寸** 排序、列宽自适应。

**双排版方案**

「旧排版方案」复选框控制排版策略，程序会记住上次的选择：

| 方案 | 策略 | 适用 |
|------|------|------|
| 混合排料（默认，不勾选） | 不区分大小件，整体优化排料 | 通用，排版更简洁 |
| 分大小件（勾选） | 大料单独排板、小料塞缝 | 零件长短差异大的订单 |

> 💡 选「混合排料」时，「开料最短尺寸」「预计用料比例」两个输入框自动置灰（该方案不需要这两个参数）。

**切刀损耗**

排版按切刀直径计算损耗：一块板切 n 块料件，损耗 (n−1)×切刀直径，余料长度已扣除该损耗。例如 3000 的板材可切 1 块 3000，但不能切 2000+1000（差一个切刀直径）。

**库存不足**

某料厚的零件在库存里找不到可用板材尺寸时，弹窗提示「库存不足，请添加库存（料厚 X）」并中止排版，需先补库存再排。

## 九、材料汇总

材料汇总按 **基材料厚** 分组统计各基材长的用料情况，用于核对订单用料与考核排版使用率。窗口与 Excel 两种形态数据同源、口径一致。

**窗口材料汇总表（排版下料页右侧）**

1. 排版完成后（或执行导出清单时）自动刷新
2. 按料厚分组：列出 基材长、数量、用料（米）、使用率，组末有加粗小计行

**Excel 材料汇总区小计行**

导出的 Excel 清单中，材料汇总区每个料厚的数据行末尾有加粗「小计」行，汇总该料厚各基材长的用料长度（米）总和与综合使用率。

> 📐 用料长度（米）= Σ(基材尺寸 × 数量) ÷ 1000；综合使用率 = (总用料 − 余料) ÷ 总用料。

## 十、下料写码（NC 码生成）

下料写码页签根据排料结果生成切割机 NC 码。左侧是参数与操作按钮，右上为写码组合列表（序号 / 基材尺寸 / 组合），右下为 NC 预览框。

**10.1 准备组合清单（三种方式）**

1. **读取排料表组合** —— 一键把排料表每块板的组合读入列表（最常用）
2. **导入表格** —— 从 Excel 导入组合，表头含「组合」列（或内容含 `[规格]` 格式）即可；序号、基材尺寸列可省略，说明行自动跳过
3. **剪切板导入** —— 复制表格内容（如 Excel 选中区域）后点击，自动解析 Tab / 空格分隔的组合数据

**10.2 预览与检查**

在写码组合列表点选任意行，NC 预览框立即显示该块板的刀路 NC 码。刀位按 首刀偏移、段长、刀径 递推，**先全部槽线、后全部切断**，与切割机格式一致——生成前务必逐行检查。

**10.3 生成 NC 文件**

1. 点「生成 NC 文件」，选择保存的基础文件夹
2. 程序自动创建子文件夹：订单名称_时间戳（如 鹏宸建筑_20260906_113000），NC 文件全部存入其中，避免混入其他项目
3. 每块板生成一个文件：订单名称板1.nc、订单名称板2.nc……与排料表行序一一对应

**10.4 双刀分段（组合含槽线时）**

组合里含槽线料（如 `[500+151]`，表示总长 651 的料在 500 处开一条槽）时，程序按「**先开槽、再切断**」自动分段：先用开槽刀（默认 T2）开出全部槽线，收刀换刀后再用切断刀（默认 T1）切断全部段。

- 每刀固定 4 行：定位 → 下刀 → 横切 → 抬刀；段尾为 `G1 Z0.` / `M5` / `M92`
- 行号为整个文件的连续编号（控制行也占号），可逐行核对是否跳号
- 生成的 NC 文件为无 BOM 纯文本，切割机读取首行不会出现非法字符

> ⚠️ 刀径、深度、首刀偏移、X 起点终点、刀号、转速、进给等参数需与切割机实际刀具 / 行程一致，首次使用前建议用一小段料试切确认。

## 十一、导出清单

| 按钮 | 行为 | 适用 |
|------|------|------|
| 导出清单 | 自动用两种方案（混合排料 / 分大小件）各排一次，取**用料最短**的方案导出，并把方案名写入 Excel 项目信息区 | 需要最优省料方案的正式清单 |
| 导出表单 | 按当前勾选的方案直接排版导出，速度快 | 日常快速出表 |

清单内容包含：**防火直管清单（订单）、开料清单（含备注）、材料汇总（含小计）、事件记录、排版清单（含组合与余料）**。文件名为 `项目名称(防火直管排版-综合清单-月日).xlsx`，保存到订单存档目录。

> 💡 同一天同一项目名重复导出会提示重名——请修改订单名称后再导出，避免覆盖已有清单。

## 十二、注意事项

1. 软件绑定当前电脑硬件，更换电脑或重装系统需技术部重新授权
2. 开料统计与排版为后台计算，运行期间请勿关闭程序
3. 排料限制建议填库存常用料长，否则大零件数量估算不准，影响排料质量
4. 库存表必须包含排版所需的全部尺寸与数量，否则排版会因库存不足中止
5. 下料写码的 NC 参数（刀径 / 深度 / 偏移 / 刀号 / 进给）需与切割机实际一致，首次使用前请试切确认
6. 导出的 Excel 文件名不能包含 `[ ]` 方括号，项目名称请避免使用（Excel 会视为工作簿引用而报错）
7. 程序仅供内部使用，请勿外传
