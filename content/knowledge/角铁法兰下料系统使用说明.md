**产品：**角铁法兰下料系统　|　**作者：**奇美星　|　**当前版本：**V1.0

角铁法兰下料系统用于角钢法兰的下料计算、排版优化与打孔孔距计算。输入法兰订单（长度 / 宽度 / 型号 / 数量），程序自动完成开料拆解、材料排版、孔位计算，最终导出可直接下发车间的综合清单。

---

## 一、软件简介

完整工作流程：

1. **订单录入** —— 手动添加或从 Excel 模板导入法兰订单
2. **开料统计** —— 按型号与内尺调整值拆解长料 / 短料
3. **角钢排版** —— 依据基材与库存，计算最省料的下料方案
4. **打孔计算** —— 按孔距要求算出每根料的孔位与孔数
5. **导出清单** —— 生成综合清单 Excel（法兰 / 开料 / 排版 / 打孔数据）

## 二、安装与启动

1. 双击安装包，按提示完成安装（默认安装到 `C:\Program Files\角铁法兰下料系统`）
2. 桌面与开始菜单生成快捷方式，双击即可启动
3. 首次启动需输入授权密码（内置于 security.ini）
4. 程序运行数据保存在安装目录，无需额外配置数据库

> ⚠️ 安装目录必须具有写入权限——程序运行时会读写存档文件（窗体数据存档.ini、基材表.ini）。安装程序已自动为安装目录授予用户写权限。

## 三、界面总览

主界面分为三个页签：

| 页签 | 功能 |
|------|------|
| 订单录入 | 登记法兰订单、维护项目与角铁材质、导入 Excel 模板 |
| 排版下料 | 维护基材与库存、执行角钢排版、查看排版结果 |
| 打孔设置 | 按孔距要求计算孔位孔数、维护特殊料件 |

## 四、参数说明

| 参数 | 说明 |
|------|------|
| 订单名称 | 本次排版的工程 / 订单名，用于生成导出的文件名，不可与已有文件重名 |
| 订单日期 | 订单登记日期 |
| 法兰类型 | 法兰的形式类别，随订单记录 |
| 内尺调整 | 内尺方式的补偿值（mm）。正数加长、负数缩短；按内尺下料时用于补偿板材厚度 |
| 角铁材质 | 角钢材质（镀锌 / 冷板等），可在材质区维护多选 |
| 孔距要求 | 打孔孔距（mm），打孔计算的依据 |
| 型号 | 角钢型号（30 / 40 / 50），决定长料的端部让量 |
| 长度 / 宽度 | 法兰内口的长度与宽度（mm） |
| 数量 | 该规格法兰的数量 |
| 开料最短尺寸 | 排版允许的最小料段长度（mm），低于此值的料段不参与排版 |
| 材料利用率 | 排版时预期的成材率（%）。设得越高越省料，但可能排不出方案——若出现「缺少长料」，请调低该值 |
| 基材长度 | 角钢原材料的单根长度（mm） |

## 五、订单录入

订单表共 5 列：**编号 / 型号 / 长度 / 宽度 / 数量**。录入有两种方式：

**方式一：手动录入**

1. 填写 编号、型号、长度、宽度、数量
2. 点击「添加」，数据写入订单表
3. 选中某行后点击「删除」可移除该行

**方式二：Excel 模板导入**

1. 点击「订单模板路径选择」，指定车间下发的 Excel 订单模板（.xlsx / .xls）
2. 点击「订单导入」，按模板批量导入订单
3. 模板路径会被记忆，下次启动无需重新选择

**项目与材质管理**

- 项目添加 / 项目删除 / 项目修改 / 项目清空 —— 维护项目名称列表
- 材质添加 / 材质删除 —— 维护角铁材质列表（已在列表中的材质不可重复添加）
- 存档位置 —— 指定导出清单的保存目录
- 表单 / 导出清单 —— 导出当前订单的综合清单

## 六、开料统计

点击「重新开料统计」后，程序按下列规则把每条订单拆成长料与短料：

| 料别 | 计算方式 | 数量 | 备注判定 |
|------|---------|------|---------|
| 长料 | 长度 + 型号 × 2 + 内尺调整值 | 数量 × 2 | 长度 = 宽度 且 型号 30 → 正长料；否则 长料 |
| 短料 | 宽度 + 内尺调整值 | 数量 × 2 | 长度 = 宽度 → 正短料；否则 短料 |

相同「尺寸 + 备注 + 型号」的记录会自动合并、数量累加。统计结果写入开料记录表（型号 / 尺寸 / 数量 / 备注）：

- **长料** = 法兰的长边段，两端各让出一个型号宽度（型号 30 即让 30mm × 2）
- **短料** = 法兰的短边段，长度为法兰宽度加内尺调整值
- 备注中的「**正**」表示该法兰长度等于宽度（正方形法兰），排版与打孔时按正方料处理

## 七、基材与库存管理

**基材表** —— 登记可用的原材料：

- 填写 基材型号、基材长度，点击「基材添加」；选中行后点击「基材删除」移除
- 基材数据保存在 `基材表.ini`，下次启动自动加载

**库存表** —— 记录车间现有库存：

- 填写 库存型号、库存长度、库存数量，点击「库存添加」
- 选中某行可载入输入框修改后重新添加；「库存删除」移除该行
- 相同型号 + 相同长度会提示合并，数量自动累加

## 八、角钢排版

点击「角钢排版」执行排版计算，程序要点：

1. 按型号分组，以基材与库存为料源，逐组寻找最省料的组合方案
2. **切刀损耗计入计算**：每根切 n 段产生 (n−1) 次切割损耗
3. 排出多套方案时自动比较、优先选用料最少的方案，相同方案自动合并
4. 结果写入排料表（型号 / 基材 / 数量 / 组合 / 使用率 / 余料），并消耗对应库存
5. 若某型号无可用库存，会提示「库存不足」，请先补充库存后重排

> 💡 材料利用率设得越高，程序越倾向把料排满；若反复排不出方案，先调低利用率再试。

## 九、打孔设置

打孔计算依据开料记录表与「孔距要求」，算出每根料的孔位与孔数：

1. 在「孔距要求」填入孔距（mm），点击「孔距计算」
2. 程序逐条读取开料记录，按备注类型（长料 / 短料 / 正长料 / 正短料）计算**大孔首距**与**大孔数量**
3. 结果写入打孔数据表单，可点击「导出表单」导出打孔数据清单
4. 「短方螺丝首孔」「长方铆钉首孔」用于设定短料与铆钉孔的首孔位置
5. 孔位计算规则会随型号尺寸自动调整（长方螺丝孔与铆钉孔按型号不同而调整）

**特殊料件管理** —— 对于孔位有特殊要求的料件，在特殊料件管理区登记后，孔距计算会优先匹配：

- 登记项：型号、尺寸、类别（长料 / 短料 / 正长料 / 正短料）、孔距要求、大孔首距、大孔数量
- 匹配条件：型号（或类别为短料）+ 尺寸 + 类别 + 孔距要求全部一致时才采用该特殊料件的孔位参数
- 已在列表中的特殊料件不可重复添加；登记内容保存在程序目录，下次启动自动加载

## 十、导出清单与表单

| 导出项 | 内容 | 文件名 |
|--------|------|--------|
| 导出清单 | 综合清单：法兰清单 + 开料清单 + 排版清单（一个 Excel 多个工作表） | `项目名称(角铁排版-综合清单-月日).xlsx` |
| 导出表单 | 按当前订单生成清单表单 | 同上 |
| 导出表单（打孔） | 角铁法兰打孔数据 | 同上 |

导出的文件保存到「存档位置」指定的目录。若提示「发现重名文件」，说明该订单名已导出过——请修改订单名称后重试，避免覆盖已有清单。

## 十一、存档与数据文件

| 文件 | 存放内容 |
|------|---------|
| `security.ini` | 授权信息（首次启动的密码验证） |
| `窗体数据存档.ini` | 界面参数记忆：开料最短尺寸、基材长度、材料利用率、角铁材质、订单模板路径、项目名称 |
| `基材表.ini` | 基材表数据（型号 / 长度） |
| `密码图标.bmp` | 启动密码窗体的图标资源，不可删除 |

以上文件均保存在程序安装目录。升级安装时，安装程序**不会覆盖已存在的同名文件**，因此已有的参数设置、基材数据与授权信息都会保留。

## 十二、注意事项

1. 导出的 Excel 文件名不能包含 `[ ]` 方括号，订单名称请避免使用（Excel 会将其视为工作簿引用而报错）
2. 排版前请确认基材表与库存表已按车间实际情况填写，否则排出的方案无法落地
3. 材料利用率与开料最短尺寸会显著影响排版结果，建议按车间常备料长设置
4. 订单名称、项目名称请勿重复，否则导出时提示重名
5. 程序仅供内部使用，请勿外传
