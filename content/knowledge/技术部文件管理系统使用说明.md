**产品：**技术部文件管理系统　|　**作者：**奇美星　|　**当前版本：**V1.8

技术部文件管理系统是风管厂技术部内部使用的**办公管理平台**——把排版文件的流转、存档、统计、追溯全管起来，顺带把技术部日常绘图放样用的 26 个辅助工具收进一个入口，点一下就启动。

> 📖 **关于本文档与安装包的关联**
> 本页是**网页版使用说明**，与本系统的安装包一一对应：
> - **安装包文件名**带版本号和日期（如 `技术部文件管理程序安装包_1.8_2026.09.24.exe`），文件名的版本号 = 本页顶部显示的版本号 = 本页「版本更新记录」的最新一行

> - 安装完成后会**自动打开本页面**（安装向导最后一页默认勾选，不想看可取消勾选）
> - 版本升级后，本页的「版本更新记录」会同步新增一行；想确认自己用的是哪版，比对安装包文件名即可

## 一、软件简介

### 它解决什么问题

技术部的日常工作有两个痛点：

- **文件散**——报价排版的、检查的、下单的，文件各人存各人电脑，找起来靠喊人，追责时说不清
- **统计难**——月底算工作量，靠翻记录、凭印象，谁做了多少平方、错了几次，没有准数

这个系统把这两件事接起来：排版文件按流程**自动归档到共享盘**、同时**入库留痕**，月底直接出工作量统计和绩效数据。另外技术部那套自己攒的绘图小工具（出图、放样、DXF、包角）也从系统里统一入口启动，不用再翻文件夹找 exe。

### 主要功能

| 模块 | 说明 |
|------|------|
| **报价排版** | 报价阶段的 CAMduct 排版文件管理、上传与留档 |
| **检查排版** | 生产阶段复查已有排版，上传企业微信云盘并留档 |
| **下单排版** | 生产阶段新增排版，上传企业微信云盘并留档 |
| **绩效看板** | 月度/年度工作量统计与绩效核算 |
| **人员信息** | 考勤管理、工作量图表统计 |
| **出错登记** | 出错情况记录、责任判定与损耗折算 |
| **图纸储存** | 图纸文件分类存档与检索 |
| **系统清量** | 系统量单文件存档 |
| **设备记录** | 型材设备信息记录 |
| **资料查询** | 图纸/资料检索 |
| **成员/材料/系数** | 部门人员、材质单价、折算系数等基础数据维护 |
| **辅助工具箱** | 一键启动 26 个绘图/放样工具程序（安装包内共附 27 个工具） |

> 📌 **关于「管件排版」「角铁排版」**：这两块功能已从本系统**拆分为独立程序**单独运行，本系统专注排版文件的流转、存档与绩效统计。需要这两块功能请向技术部索取对应的独立程序。

### 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 网络 | 局域网（需能访问 MySQL 数据库服务器） |
| 数据库 | MySQL（部署在局域网服务器上） |
| 依赖 | 部门共享盘符已映射、企业微信云盘已配置 |

## 二、安装与登录

### 安装

1. 从技术部主管处获取安装包：`技术部文件管理程序安装包_版本号_日期.exe`
2. 双击运行，按向导提示走完安装流程
3. 若提示"程序正在运行"，点【是】自动关闭旧程序后继续安装
4. 安装完成后，桌面和开始菜单会生成快捷方式

**安装向导里会看到什么：**

| 步骤 | 内容 |
|------|------|
| 选择安装位置 | 默认 `C:\Program Files\技术部文件管理系统`，一般不用改 |
| **软件简介页** | 安装前会显示**《安装简介》**——软件简介、27 个子模块清单、**版本更新记录**、作者简介 |
| 安装进度 | 自动复制主程序 + 26 个辅助工具 + 配置文件；**已存在的配置/数据文件会自动跳过，不会覆盖你的数据** |
| **完成页** | 勾选项：**「打开使用说明（网页版）」**（默认已勾选）+「立即运行技术部文件管理系统」 |

**关于"安装完成后自动打开使用说明"：**

- 安装到最后一页时，**「打开使用说明（网页版）」默认是勾选状态**，点【完成】会自动用浏览器打开本页面
- 不想马上看就**取消勾选**，再点【完成】
- 这个页面随时可以打开：浏览器访问 `https://tangguoqi.top/knowledge/技术部文件管理系统使用说明/`，或从技术部主管处索取网址
- **安装包 ↔ 说明文档的对应关系**：安装包文件名里的版本号（如 `_1.7_`）= 安装时显示的《安装简介》版本号 = 本页「版本更新记录」最新一行

### 更新程序

有新版本时，直接用**新安装包重新安装一遍即可**（覆盖安装），不需要先卸载：

1. 关闭正在运行的程序（或让安装包自动关闭）
2. 双击新安装包完成安装
3. **配置和数据不会丢**——安装包只更新程序文件（exe/dll/手册）；本地配置文件（`.ini`）和数据库文件（`.db`）已存在的一律跳过，不会覆盖

### 卸载程序

1. Windows 设置 → 应用 → 找到「技术部文件管理系统」→ 卸载
2. 或从开始菜单：技术部文件管理系统 → 卸载技术部文件管理系统
3. ⚠️ 卸载会删除程序目录（含本地配置文件和数据文件），确认无需要保留的本地数据后再操作

### 首次登录

1. 双击桌面快捷方式启动程序
2. 在登录界面输入**局域网 IP 地址**（数据库服务器地址）
3. 选择或输入**姓名**
4. 输入**密码**，点击【登录】

> 💡 首次使用需点击【注册】按钮创建账号，注册后即可登录。局域网地址由管理员统一告知，一般为 `192.168.x.x` 格式。

### 更新 IP

如果数据库服务器 IP 发生变更，点击登录界面的【更新IP】按钮，输入新地址后保存即可。系统会将地址存入本地配置文件，下次启动自动读取。

## 四、核心业务操作

三个排版页签的操作逻辑一致：**确认日期 → 确认三个路径 → 点执行按钮 → 系统自动归档+入库**。区别只在文件来源和去向。

### 4.1 报价排版

**适用场景**：订单处于报价阶段，需要用 CAMduct 对异形件排版，按排版面积（平方数）向跟单报价。

1. 切换到【报价排版】页签
2. 确认日期（默认当天，可手动调整）
3. 确认三个路径：
   - **本地排版路径** —— CAMduct 生成的排版文件所在目录
   - **本地留档路径** —— 个人本地备份目录
   - **上传排版路径** —— 部门共享盘中对应文件夹
4. 点击【执行排版报价留档】
5. 系统自动复制文件到留档目录和上传目录，并在数据库生成记录

**文件流向**：CAMduct 本地文件 → 本地留档 + 部门共享盘 → 数据库记录入库

> 💡 报价平方数通过排版文件报给跟单人员。

### 4.2 检查排版

**适用场景**：订单已下发生产，针对报价阶段已排过版的项目进行复查确认，确保生产用图无误。

1. 切换到【检查排版】页签 → 确认日期
2. 确认三个路径：
   - **报价存档路径** —— 之前报价阶段留档的文件位置
   - **检查留档路径** —— 部门共享盘中的检查留档文件夹
   - **检查上传路径** —— 企业微信云盘对应目录
3. 点击【执行检查上传留档】

**文件流向**：报价存档文件 → 企业微信云盘 + 部门共享盘留档 → 数据库记录入库

### 4.3 下单排版

**适用场景**：订单已下发生产，针对之前没有排版但需要排版生产的项目，新做排版后上传。

1. 切换到【下单排版】页签 → 确认日期
2. 确认三个路径：
   - **本地排料路径** —— 新排版文件所在本地目录
   - **下单留档路径** —— 部门共享盘中的下单留档文件夹
   - **下单上传路径** —— 企业微信云盘对应目录
3. 点击【执行下单上传留档】

**文件流向**：本地排版文件 → 企业微信云盘 + 部门共享盘留档 → 数据库记录入库

### 4.4 路径设置说明

每个页签的路径均可通过【设置】按钮选择目录，设置后自动保存到本地配置文件，下次启动无需重复设置。点击路径旁的【打开】按钮可快速在资源管理器中打开对应目录。

> ⚠️ 路径设置错误会导致文件上传失败！请确保共享盘符已正确映射且有写入权限。

## 五、辅助功能模块

### 5.1 绩效看板

用于查看技术部月度/年度工作量统计和绩效考核数据。

- **月度汇总**：选择年月后自动加载当月工作量数据
- **工作量核算**：按人员统计报价/检查/下单的平方数
- **绩效核算**：结合出错、纪律等因素的综合评分

### 5.2 人员信息

管理技术部考勤与人员工作表现统计。

- 考勤表：按月记录出勤情况，支持编辑和保存
- 排版统计图表：报价平方数 / 下料平方数趋势
- 表现统计图表：出错损耗 / 纪律问题统计
- 职能信息：人员岗位职能一览

### 5.3 出错登记

用于记录技术部工作中的出错情况，追溯责任与核算损耗。登记内容包括：

- 项目名称、出错时间
- 责任成员、连带责任人
- 出错类型（分类选择）
- 简要说明 + 详细报告
- 损耗成本折算（材质、平方、单价 → 自动计算）

> 💡 出错记录将关联到绩效核算，请如实填写。

### 5.4 图纸储存

将技术部绘制的图纸文件统一存档到网络目录，方便日后查阅。

1. 选择文件（支持多选）
2. 填写：图纸类别、对应跟单、制图人员、项目名称
3. 确认存档地址（首次需设置）
4. 点击【保存文件】

### 5.5 系统清量

存档系统量单相关文件（设备数量、对应跟单、系统平方数等）。

1. 选择量单文件
2. 填写：对应跟单、项目名称、设备数量、作业类型、系统平方
3. 确认存档地址
4. 点击【保存文件】

### 5.6 设备记录

记录各类型材设备的规格信息，便于查询和追溯。按类别筛选设备，记录型材说明、规格尺寸、法兰接口，支持文件附件存档。

### 5.7 辅助工具箱

集成了技术部常用的绘图和放样外部程序，点按钮一键启动（共 26 个工具，按界面上的 5 个分组排列）。

| 分组 | 工具按钮 |
|------|----------|
| **出图工具**（7） | 静压箱绘制、方法兰绘制、圆法兰绘制、烟罩折弯图、任意弯制图、S弯分段图、内R转直位 |
| **表单工具**（2） | 共板打孔、圆管开平 |
| **放样工具**（6） | 防火板内外菱三通、烟包绘图放样、油烟罩绘图放样、吊装烟罩绘图放样、沉水弯绘图放样、保温管支撑件放样 |
| **DXF 绘制工具**（6） | 锯齿孔制图、阻抗片制图、圆管微联下料、圆管剪口制图、压条框制图、导流片制图 |
| **防火包角**（5） | S弯包角制图、弯头包角制图、侧三通包角制图、正三通包角制图、四通包角制图 |

**用法**：点按钮即启动对应程序，程序文件就在本系统的安装目录里，**装一次全都有**，不用另外去找 exe。

> 💡 各工具的详细用法见各自的帮助文档。其中：
> - **内R转直位**：输入任意角度弯头的内R和直位（或排版R），自动换算另一个并实时画出排版示意图，外弧同步转换，供下料排版参考
> - **保温管支撑件放样**：参数化制图，输入参数直接出图
> - 工具程序更新后，用新安装包覆盖安装一次即可，工具也会一起更新
> - 安装包内共附 **27 个工具程序**（比界面按钮多 1 个「自动排版」），该程序不在工具窗里，需要时可直接到程序安装目录双击运行

### 5.8 基础数据管理

- **成员管理**：添加/修改/删除部门人员信息（姓名、电话、部门）
- **材料编辑**：维护材质类型、厚度、单价等基础数据
- **系数折算**：管理各类别的折算系数（用于绩效核算等）

## 七、业务流程总览

**报价阶段**
跟单发来项目需求 → 技术员用 CAMduct 排版 → 按平方数报价给跟单 → 排版文件上传部门共享盘 + 本地留档 → 系统记录入库

**生产阶段（已排版项目）**
订单下发生产 → 检查之前的排版 → 确认无误后上传企业微信云盘 + 部门共享盘留档 → 系统记录入库

**生产阶段（未排版项目）**
订单下发生产 → 新做排版 → 上传企业微信云盘 + 部门共享盘留档 → 系统记录入库

## 八、常见问题

**Q：登录时提示连不上数据库？**
A：检查登录界面的 IP 地址是否正确（找管理员确认），以及本机能否访问局域网。IP 变了用【更新IP】按钮改。

**Q：上传失败，提示路径错误？**
A：检查三个路径是否都设置了、共享盘符是否已映射、有没有写入权限。路径旁的【打开】按钮可以快速验证目录是否可达。

**Q：点了执行按钮但记录表里没数据？**
A：先确认日期是否正确（默认当天），再确认本地路径下确实有排版文件。

**Q：怎么确认自己装的是哪个版本？**
A：两个地方都能看：① **程序主界面上显示的版本号**（如 `版本号:V1.8`，安装时自动写入，与实际安装包一致）；② **安装包文件名**（末尾带版本号和日期，如 `_1.8_2026.09.24`）。再对照本页第九节的更新记录。

**Q：安装包会覆盖我的数据吗？**
A：不会。安装包只更新程序文件（exe/dll/手册），配置文件（.ini）和数据库文件（.db）**已存在的一律跳过**，不会覆盖你的本地数据。

**Q：装完了，但使用说明页面没自动打开？**
A：看安装向导**最后一页**——「打开使用说明（网页版）」如果没勾选就不会打开（默认是勾选的），可能是手动取消了。不影响使用，随时可以手动访问：
`https://tangguoqi.top/knowledge/技术部文件管理系统使用说明/`

**Q：使用说明网页打不开？**
A：该页面在公网，需要能上网。断网情况下可以先看安装过程里的《安装简介》，或找技术部要一份离线说明。

**Q：忘记登录密码了怎么办？**
A：联系管理员在数据库里重置，或重新注册一个账号。

**Q：桌面快捷方式不见了？**
A：从开始菜单 →「技术部文件管理系统」右键发送到桌面；或直接到安装目录（默认 `C:\Program Files\技术部文件管理系统`）双击「技术部文件管理系统.exe」。

**Q：辅助工具点按钮没反应 / 提示找不到程序？**
A：多半是工具程序文件缺失或被挪走了。用**新安装包覆盖安装一次**即可修复（工具程序会重新释放到安装目录）。
